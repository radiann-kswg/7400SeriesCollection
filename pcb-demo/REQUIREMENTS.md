# 7400 Series Specimen Tiles — 要件定義書

> **コンセプト**: 「本物の元素を封入した周期表」の 7400 シリーズ版。
> 収集した現物の DIP IC をソケットに挿し、**その IC が実際に動いている状態**で展示する。
> IC は基板に固定せず抜き差し可能とし、コレクションとしての価値を損なわない。

- 版: 0.4（2026-09-16 改訂: R6 パネライズ手段に **KiKit** を採用・検証、R8 は SHOU HAN へ図面照会中、クロック入力のチャタリングは許容する方針で確定）
- 作成日: 2026-09-16
- ステータス: Phase 0（要件定義）完了 / Phase 1 ほぼ完了（残: SHOU HAN からの図面回答待ち、ユーザーが JLCONE で実見積もりを取得）。残り9型番の生成（Phase 2）は別セッションで対応。[作業ログ](../work-in-progress/2026-09-16_specimen_tile_phase1.md)

## 2. 設計要件

### 2.1 対象 IC

所持 162 型番のうち、KiCAD 標準ライブラリでパッケージが確定できた 120 型番の内訳:

| パッケージ                   | 件数 | 列間隔 | 本方式での扱い       |
| ---------------------------- | ---: | ------ | -------------------- |
| DIP-14                       |   45 | 300mil | 標準タイル           |
| DIP-16                       |   59 | 300mil | 標準タイル           |
| DIP-20                       |   14 | 300mil | 標準タイル           |
| DIP-24（74x154 / 74x181）    |    2 | 600mil | 変異タイル（Phase 4） |

**300mil の 20 ピンソケット 1 種類で 118/120 = 98% をカバーする。** DIP-14/16 は DIP-20 と列間隔・ピッチが同一のため、同じソケットにピン 1 側へ端寄せして挿入できる。

### 2.2 共通トポロジ（全タイル同一）

詳細仕様は [`_carrier/README.md`](_carrier/README.md)。要点のみ:

- DIP-20 300mil ソケット（THT・手はんだ）を中央に配置
- 電源に割り当てた 2 接点を除く**最大 18 接点それぞれに I/O セル**を実装
  - **SPDT スイッチ + 1kΩ 直列** — 入力を +5V / GND のどちらかに必ず駆動（フローティング禁止）
  - **LED + 4.7kΩ 直列** — 状態表示
- デカップリング 100nF をソケット直近に 1 個
- 給電は 2 ピンヘッダ（+5V / GND）
- 抵抗値は 1kΩ と 4.7kΩ の 2 種類のみ

**安全規則（必須）**: 入力駆動は**必ず直列抵抗を経由**する。共通トポロジでは「そのピンが入力か出力か」を基板側が知り得ないため、出力ピンのスイッチを誤って閉じても電流が制限され IC を破壊しない構造にすること。

### 2.3 型番ごとに変わるもの（これだけ）

| 差分         | 内容                                                                                  |
| ------------ | ------------------------------------------------------------------------------------- |
| ① 電源接点   | VCC / GND をどのソケット接点に接続するかを銅箔で焼き込む                              |
| ② セル種別   | 接点ごとに pinspec の方向で決める。入力・双方向 = スイッチ + LED。出力・3 ステート = **LED のみ**（`SWk`・`R(20+k)` を DNP）。未使用（20−n 接点）・NC・オープンコレクタ = 全部 DNP |
| ③ シルク     | 汎用型番・機能名（EN/JP）・ピン名・カテゴリ                                           |

回路トポロジ・部品定数・フットプリント・外形は**全型番で不変**。

### 2.4 IC 挿入規約

ピン 1 をソケット接点 1 に合わせ、ピン 1 側へ端寄せして挿入する。n ピン IC の接点マッピング:

```text
IC pin i  (i <= n/2)  ->  ソケット接点 i
IC pin i  (i >  n/2)  ->  ソケット接点 i + (20 - n)
```

例（DIP-14）: pin 7 → 接点 7、pin 8 → 接点 14、pin 14 → 接点 20。

### 2.5 電源ピンが非標準の型番

所持品のうち VCC/GND が角ピンにない型番。**生成時に個別確認が必須**:

| 型番   | VCC | GND |
| ------ | --: | --: |
| 74x73  |   4 |  11 |
| 74x75  |   5 |  12 |
| 74x90  |   5 |  10 |
| 74x93  |   5 |  10 |

## 3. 製造要件（JLCPCB）

| 項目                   | 値                                             | 備考                                             |
| ---------------------- | ---------------------------------------------- | ------------------------------------------------ |
| 組立サービス           | **Economic**（SMD のみ・上面のみ）             | THT を含めると Standard になり費用増             |
| PCBA 最小数量          | **5 枚**                                       | パイロットは 3 パネル × 5 枚 = 60 タイル         |
| Extended 部品          | **$3 / 種**                                    | Basic 部品を優先して選定する                     |
| 基板                   | 2 層 / 厚 1.6mm / 銅箔 1oz                     | 既存テンプレートの既定を踏襲                     |
| 最小パターン幅・間隔   | JLCPCB 下限 0.127mm。**本設計は 0.25mm 以上**  | 下限に張り付かない                               |
| 基板端クリアランス     | 銅箔は端から 0.5mm 以上                        | V-cut 分離のため下限 0.3mm より広く取る          |
| パネル                 | 100×100mm、V-cut、2×2 = 4 タイル               | 最安価格帯                                       |
| 手はんだ部品           | DIP-20 ソケット、2 ピンヘッダ                  | THT。JLCPCB には渡さない                         |

### 3.1 提出ファイル

| ファイル          | 形式 | 注意                                                                             |
| ----------------- | ---- | -------------------------------------------------------------------------------- |
| Gerber + ドリル   | ZIP  | パネル単位。Edge.Cuts が閉じていること                                           |
| BOM               | CSV  | 列名は `Comment` / `Designator` / `Footprint` / **`LCSC Part #`**（表記ゆれで弾かれる） |
| CPL（実装座標）   | CSV  | 列は `Designator` / `Mid X` / `Mid Y` / `Layer` / `Rotation`                      |

**CPL に BOM へ無い designator を含めないこと。** 基準マーク・取付穴・THT 部品が CPL に残っているとアップロードが不可解なエラーで弾かれる。BOM を先に確定し、CPL をその designator 集合で絞り込む。

## 4. 検証要件

| 段階       | 検証                                                          | 合格条件       |
| ---------- | ------------------------------------------------------------- | -------------- |
| 回路図     | `kicad-cli sch erc`（既存 `scripts/verify_kicad_sch.py`）      | エラー 0       |
| レイアウト | `kicad-cli pcb drc`（JLCPCB ルール）                           | エラー 0       |
| パネル     | Edge.Cuts の閉曲線・V-cut 線の直線性                           | 目視           |
| 製造データ | CPL の回転（特に LED と DIP スイッチ）、LCSC 在庫             | 目視・在庫確認 |
| 実機       | パイロット 12 種で全 I/O セルの点灯と入力切替                  | 全セル動作     |

**一次資料照合ルール（AGENTS.md）は本プロジェクトにも適用される。** 発注前に確定が必要な一次資料情報は **ピン数・VCC/GND の位置・各ピンの方向**（D15）。確認結果は `_carrier/pinspec/{型番}.json` に、参照 PDF・ページ・確認日・読み取り信頼度とともに記録する。真理値表や電気特性は不要。

### 4.1 ピン仕様の確認工程（基板生成の前段）

1. `datasheets/_download/` に対象型番のデータシートがあるか確認する。無ければ `scripts/fetch_missing_datasheets.py --part {型番}` でメーカー公式サイトから収集する（TI の SN74HC / CD74HC を優先）
2. `scripts/render_datasheet_pages.py --pdf {PDF} --pages 1-4` で PNG 化し、ピン機能表を目視で読む（CLAUDE.md の手順。信頼度 85% 未満はユーザーに確認）
3. `_carrier/pinspec/{型番}.json` に記録する。`dir` は `input / output / tri_state / open_collector / bidirectional / nc / power / ground`、`attr` に `active_low` / `clock` 等
4. 共通回路で扱えないピン（オープンコレクタ出力、チャタリングが問題になるクロック入力など）は `notes` に書き、ユーザーに相談する

### 4.2 クロック入力のチャタリングについて（決定事項、2026-09-16）

パイロット12型番のうち 74x393・74x164・74x595 はスライドスイッチで CLK ピンを駆動する。機械式スイッチのチャタリングで複数エッジが入りうるが、
**デバウンス回路は追加せず許容する**（D が安定していれば同じ値を再ラッチするだけで実害なしという見立てに基づく）。パイロットの実機検証で
誤動作が確認された場合のみ、共通トポロジ全体への影響（部品点数・コスト増）を踏まえて再検討する。

## 5. コスト管理

支配要因は次の 3 つ。設計判断はこの順に効く。

1. **1 タイルあたりの SMD 実装点数** — I/O セルは 1 接点あたり 3 部品（LED / `Rled` / `Rd`）。18 接点＋スイッチ＋デカップリングで最大約 61 点
2. **パネル数**
3. **Extended 部品の種類数**（$3/種）

**削減レバー**: I/O セルの抵抗 36 本を **4 素子の抵抗アレイ 9 個**にまとめると実装点数が約 61 → 約 34 に減る。LCSC では 1kΩ / 4.7kΩ とも Basic（C20197 / C1980）。ただし Economic の組立費ははんだ点数課金のため削減額は小さく、50×50mm では個別 0603 で収まったので**現状は不採用**（D14）。

**見積もりは未取得。** JLCPCB の公式 API は審査制のため未申請であり、正確な金額はクォート画面で取得する。Phase 1 完了時点で実見積もりを取り、30,000 円を超える場合は次の順に縮退する:

1. 抵抗アレイ化で実装点数を削減
2. DIP スイッチを廃しタクトスイッチのみにする（入力状態の保持を諦める）
3. パイロットを 1 パネル 6 種に縮小

## 6. データ管理方針

`getstarting/` 配下（入手履歴・購入予定・ウィッシュリスト）は**購入先・コメントを含む私物情報**のため git 追跡外とする。データシート PDF と同じ扱い。

- 実施済み: `.gitignore` に追加し `git rm --cached` で追跡解除。ファイルは手元に残るので、`getstarting/` を参照するスクリプト 13 本は無改修で動作する
- git 履歴には過去のコミットが残るが、リポジトリは現在 **private**（fork 0 / star 0）のため外部露出はない
- **公開に踏み切る時点で、新規リポジトリへスカッシュ移行する**（`filter-repo` による履歴書き換えは行わない）
- 所持メーカー型番のリストは生成物 487 ファイル（`pcb-demo/**/README.md`、`*.kicad_sch` の title block、`usage/**/01_basic_function_demo.md`）に焼き込まれている。これは「どの型番向けに設計したか」という設計情報でもあるため残す。公開時に隠す場合は別途生成し直すこと

## 8. 非目標（やらないこと）

明示的にスコープ外とする。後から必要になった場合は本書を改版してから着手する。

- **型番固有の意味のあるデモ回路**（カウンタ用の発振器、デコーダ用の 7 セグ表示など）。162 通りの設計と検証が必要になりコストが二桁合わない
- **頒布・販売**（D2）
- **OSHWA 認証**
- **CI による自動検証**（D11）
- **タイル間の物理フレーム・額装**（Phase 4 以降に検討）
- **逆挿し・誤挿入に対する保護回路**
