# 共通キャリア設計仕様（Specimen Tile v0.1）

全タイルで共通の回路トポロジ。型番ごとに変わるのは**電源ピン配線・未実装セル・シルクの 3 点だけ**（→ [`../REQUIREMENTS.md`](../REQUIREMENTS.md) §2.3）。

- 版: 0.6（2026-09-17: 入力接点の LED 表示を廃止しスイッチのみに変更（REQUIREMENTS D25）。2026-09-16: Rd を 220Ω に変更（旧 1kΩ、REQUIREMENTS D16）。LED を負論理=赤／通常=白の2色に変更（D22）。クロック入力クリーンアップ回路（タクトスイッチ+RC+74x1G14）を実装・DRC/ERC検証済み（REQUIREMENTS §4.2/D17・D24））
- 対象: DIP-14 / DIP-16 / DIP-20（300mil）= 所持品の 118/120

```text
              │

  ┌─ I/O セル（信号ピン 1 つあたり。最大 18 セル）──────────┐

  │   GND ──o  \___ Rd 1k ───┬─── ソケット接点 k ─── IC ピン │
  │                          │                               │
  │                          └─ Rled 4.7k ─ LED ─ GND        │
  └──────────────────────────────────────────────────────────┘
```

## 2. I/O セルの回路方式

### 2.1 採用案: SPDT スイッチ + 直列抵抗（プルダウン無し）

スイッチで入力を **+5V か GND のどちらかに必ず接続**し、間に 220Ω を挟む（旧 1kΩ、REQUIREMENTS D16）。

**この方式を採る理由（D10 からの変更）**: 要件定義 D10 で想定した「SPST スイッチ + 10kΩ プルダウン」は、**TTL ファミリで成立しない**。74LS の入力は L のとき最大 0.4mA を吐き出すため、10kΩ プルダウンでは入力電圧が 0.4mA × 10kΩ = 4V まで浮き、VIL(max) 0.8V を大きく超えて L と認識されない。SPDT なら L 側でも 1kΩ を介して GND に落ちるため 0.4V に収まり、**CMOS と TTL の両方が動く**。副次的に、プルダウン抵抗 18 本が不要になり部品点数もむしろ減る。

### 2.2 定数と動作点

| 記号   | 値    | 役割                     |
| ------ | ----- | ------------------------ |
| `Rd`   | 220 Ω | 入力駆動の直列抵抗（旧 1kΩ、D16） |
| `Rled` | 4.7 kΩ | LED 電流制限             |
| LED    | 0603 赤（高効率品） | 状態表示   |

計算（VCC = 5V、LED 順方向電圧 Vf ≈ 2.0V）:

| 条件                           | 結果      | 判定                                                |
| ------------------------------ | --------- | --------------------------------------------------- |
| スイッチ H 側（LED 負荷込み）  | 約 4.4V   | 74HC VIH 3.5V / 74LS VIH 2.0V を満たす              |
| スイッチ L 側（74LS の IIL 0.4mA、Rd=220Ω） | 約 0.09V  | VIL(max) 0.8V を満たす（旧 1kΩ では 0.4V。220Ω化でマージン拡大、S/H 系の大きい IIL にも対応、D16） |
| IC 出力が H のときの LED 電流  | 約 0.62mA | 高効率 LED なら室内で視認可。Phase 1 で実物調整     |
| **出力ピンのスイッチを誤操作したときの電流（Rd=220Ω）** | **約 22.7mA（公称）/ 約 25.1mA（Vcc+5%・R-5%の最悪条件）** | **要注意**: 74HC 絶対最大定格 ±25mA に対しほぼ余裕が無く、最悪条件では超過し得る。1% 級抵抗の使用、またはパイロットに含む各ファミリの個別データシートでの再確認を推奨（発注前の宿題） |

**安全規則**: `Rd` は**出力ピンや双方向ピンを誤って駆動したときの電流制限器を兼ねる**ため、**省略は禁止**。現行値は 220Ω固定（D16）で、上表の通り 74HC 絶対最大定格に対するマージンが小さいため、これより**低い値への変更は不可**（誤操作時の電流がさらに増える）。出力接点はスイッチと `Rd` を DNP にする（REQUIREMENTS D15）が、フットプリントは残す。

### 2.3 廉価案（TTL 非対応）

SPDT スイッチの単価が見積もりを圧迫する場合のみ、**SPST + 10kΩ プルダウン**に落とす。この場合 **TTL（LS/S/ALS/F/H）ファミリは動作対象外**となり、CMOS（HC/HCT/AC/ACT/AHC/LVC）専用になる。採否は Phase 1 の LCSC 価格確認で判断する。

## 3. 部品構成（1 タイル）

| Ref            | 部品                        | 数         | 実装       |
| -------------- | --------------------------- | ---------: | ---------- |
| `U1`           | DIP-20 ソケット 300mil       |          1 | **手はんだ** |
| `J1`           | 2 ピンヘッダ 2.54mm（+5V/GND） |          1 | **手はんだ** |
| `D1`–`D20`     | LED 0603（`active_low` 出力=赤 C2286 / 通常出力=白・部品番号未選定。D22） | 最大 18 | JLCPCB |
| `R1`–`R20`     | `Rled` 4.7kΩ 0603（C23162）   | 最大 18    | JLCPCB     |
| `R21`–`R40`    | `Rd` 220Ω 0603（部品番号未選定、実装確定時に選定。D16） | 最大 18 | JLCPCB |
| `SW1`–`SW20`   | SPDT スイッチ MSS12C02LS-BB2.0（C3008585） | 最大 18 | JLCPCB  |
| `C1`           | 100nF 0603（C14663）          |          1 | JLCPCB     |

SMD 実装点数は最大約 61。**抵抗を 4 素子アレイにまとめると 36 → 9 個に減り、合計約 34 点**になる（→ REQUIREMENTS §5）。アレイも Basic で揃うが、50×50mm では個別 0603 で収まったため現状は個別（REQUIREMENTS D14）。スイッチだけが Extended。

抵抗値は `Rled` と `Rd` の 2 種類のみ。部品種類を増やさないこと。

## 4. リファレンス指定子の命名規則

生成スクリプトが機械的に参照できるよう、**ソケット接点番号 k（1〜20）と 1 対 1 に対応させる**:

| 部品         | Ref     |
| ------------ | ------- |
| スイッチ     | `SWk`   |
| LED          | `Dk`    |
| `Rled`       | `Rk`    |
| `Rd`         | `R(20+k)` |
| ソケット接点 | `U1` パッド `k` |

例: 接点 7 → `SW7` / `D7` / `R7` / `R27` / `U1` パッド 7。

この規則を崩すと型番別生成（電源接点の差し替えと DNP 指定）が成立しないため、**手作業で振り直さないこと**。

## 5. 寸法・レイアウト規約

| 項目               | 値                                       |
| ------------------ | ---------------------------------------- |
| 外形               | 50 × 50 mm（100×100mm パネルに 2×2。REQUIREMENTS D9） |
| 層数 / 厚み / 銅箔 | 2 層 / 1.6mm / 1oz                       |
| 最小パターン幅     | 0.25mm（JLCPCB 下限 0.127mm には張り付かない） |
| 基板端クリアランス | 銅箔は端から 0.5mm 以上（V-cut 分離のため） |
| 実装面             | **上面のみ**（Economic 組立の制約）      |
| `U1` 配置          | タイル中央に横置き。ピン 1 を左下（接点 1〜10 が下段、20〜11 が上段） |
| `C1` 配置          | ソケット左の `J1` 横。標準配置の VCC（接点 20）から約 4mm。非標準の型番（§6.4）では離れる |
| I/O セル配置       | 接点 k の列を 4.6mm ピッチで並べる（下段は接点 1→10、上段は 20→11 を左から）。1 列は外周側から スイッチ → LED / `Rk` / `R(20+k)` → ソケットへの引き出し |
| 電源               | +5V は外周レール（上・下・左）とソケット下を通るバス。GND は裏面ベタ |
| シルク             | 各列のピン名（VCC/GND 含む）、型番・機能名（英・和）、給電表示。裏面に版・カテゴリ・ライセンス |

I/O セルは接点順に規則的に並べる。これにより自動配線が不要になり（→ REQUIREMENTS §9 R5）、シルクのピン名とも視覚的に対応する。

## 6. 型番別の生成規則

### 6.1 接点マッピング

n ピン IC をピン 1 側へ端寄せして挿入する前提:

```text
IC pin i  (i <= n/2)  ->  ソケット接点 i
IC pin i  (i >  n/2)  ->  ソケット接点 i + (20 - n)
```

### 6.2 差分の適用

| 差分         | 規則                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| ① 電源接点   | 型番の VCC / GND ピンを §6.1 で接点に変換し、その接点を +5V / GND ベタに接続。**I/O セルは実装しない** |
| ② セル種別   | `pinspec/{型番}.json` の `dir` で決める。`input` → **スイッチのみ**（`Rk`・`Dk` を DNP、REQUIREMENTS D25）。`output` / `tri_state` → `SWk`・`R(20+k)` を DNP（LED のみ）。`bidirectional` は D19 により生成停止。未使用接点・`nc`・`open_collector` → 全部 DNP。DNP は BOM・CPL から除外 |
| ③ シルク     | 汎用型番・機能名（EN / JP）・カテゴリ・各接点のピン名                                    |

### 6.3 実装セル数

| パッケージ | 実装する I/O セル |
| ---------- | ----------------: |
| DIP-14     | 12                |
| DIP-16     | 14                |
| DIP-20     | 18                |

### 6.4 電源ピンが非標準の型番

[`../REQUIREMENTS.md`](../REQUIREMENTS.md) §2.5 の 4 型番（74x73 / 74x75 / 74x90 / 74x93）は VCC/GND が角ピンにない。生成時に**一次資料で個別確認**すること。角ピン決め打ちのロジックを書かない。

## 7. 設計上の禁止事項

1. `Rd` の省略・220Ω 未満への変更（§2.2 の安全規則。現行値は D16 で 220Ω に固定）
2. §4 のリファレンス命名規則を崩すこと
3. 抵抗値を 2 種類より増やすこと
4. 裏面への SMD 部品配置（Economic 組立は上面のみ）
5. 電源ピン位置を「角ピン」と決め打ちすること（§6.4）
6. 一次資料で VCC/GND・ピン方向を確認していない（`pinspec` の無い）型番のタイルを発注対象に入れること

## 9. 生成

```powershell
& 'C:\Program Files\KiCad\10.0\bin\python.exe' scripts\generate_specimen_tile.py 74x00 74x244 74x273
```

- 出力: `tiles/{型番}/{型番}_tile.kicad_{sch,pcb,pro}`、専用フットプリント `Specimen.pretty/`
- ピン数・VCC/GND・各ピンの方向は `pinspec/{型番}.json` から読む（作り方は REQUIREMENTS §4.1）。無い型番はエラーで止まる
- 仕様を変えるときはスクリプトを直して再生成する。生成物を手で編集しない
- 検証: `kicad-cli sch erc --severity-all` と `kicad-cli pcb drc --severity-all --schematic-parity`
