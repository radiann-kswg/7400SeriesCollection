# 共通キャリア設計仕様（Specimen Tile v0.1）

全タイルで共通の回路トポロジ。型番ごとに変わるのは**電源ピン配線・未実装セル・シルクの 3 点だけ**（→ [`../REQUIREMENTS.md`](../REQUIREMENTS.md) §2.3）。

- 版: 0.1（未実装 / Phase 1 で作図・検証）
- 対象: DIP-14 / DIP-16 / DIP-20（300mil）= 所持品の 118/120

---

## 1. ブロック構成

```text
        +5V ──┬──────────────────────────────── 電源ピン（型番依存）
              │
             C1 100nF
              │
        GND ──┴──────────────────────────────── GND ピン（型番依存）

  ┌─ I/O セル（信号ピン 1 つあたり。最大 18 セル）──────────┐
  │                                                          │
  │   +5V ──o                                                │
  │          \  SW（SPDT）                                   │
  │   GND ──o  \___ Rd 1k ───┬─── ソケット接点 k ─── IC ピン │
  │                          │                               │
  │                          └─ Rled 4.7k ─ LED ─ GND        │
  └──────────────────────────────────────────────────────────┘
```

## 2. I/O セルの回路方式

### 2.1 採用案: SPDT スイッチ + 直列抵抗（プルダウン無し）

スイッチで入力を **+5V か GND のどちらかに必ず接続**し、間に 1kΩ を挟む。

**この方式を採る理由（D10 からの変更）**: 要件定義 D10 で想定した「SPST スイッチ + 10kΩ プルダウン」は、**TTL ファミリで成立しない**。74LS の入力は L のとき最大 0.4mA を吐き出すため、10kΩ プルダウンでは入力電圧が 0.4mA × 10kΩ = 4V まで浮き、VIL(max) 0.8V を大きく超えて L と認識されない。SPDT なら L 側でも 1kΩ を介して GND に落ちるため 0.4V に収まり、**CMOS と TTL の両方が動く**。副次的に、プルダウン抵抗 18 本が不要になり部品点数もむしろ減る。

### 2.2 定数と動作点

| 記号   | 値    | 役割                     |
| ------ | ----- | ------------------------ |
| `Rd`   | 1 kΩ  | 入力駆動の直列抵抗       |
| `Rled` | 4.7 kΩ | LED 電流制限             |
| LED    | 0603 赤（高効率品） | 状態表示   |

計算（VCC = 5V、LED 順方向電圧 Vf ≈ 2.0V）:

| 条件                           | 結果      | 判定                                                |
| ------------------------------ | --------- | --------------------------------------------------- |
| スイッチ H 側（LED 負荷込み）  | 約 4.4V   | 74HC VIH 3.5V / 74LS VIH 2.0V を満たす              |
| スイッチ L 側（74LS の IIL 0.4mA） | 約 0.4V   | VIL(max) 0.8V を満たす                              |
| IC 出力が H のときの LED 電流  | 約 0.62mA | 高効率 LED なら室内で視認可。Phase 1 で実物調整     |
| **出力ピンのスイッチを誤操作したときの電流** | **5mA**   | 74HC 絶対最大定格 ±25mA 以内。連続でも破壊しない    |

**安全規則**: 共通トポロジは「そのピンが入力か出力か」を知り得ない。`Rd` は**出力ピンを誤って駆動したときの電流制限器を兼ねる**ため、**省略も 470Ω 以下への変更も禁止**。

### 2.3 廉価案（TTL 非対応）

SPDT スイッチの単価が見積もりを圧迫する場合のみ、**SPST + 10kΩ プルダウン**に落とす。この場合 **TTL（LS/S/ALS/F/H）ファミリは動作対象外**となり、CMOS（HC/HCT/AC/ACT/AHC/LVC）専用になる。採否は Phase 1 の LCSC 価格確認で判断する。

## 3. 部品構成（1 タイル）

| Ref            | 部品                        | 数         | 実装       |
| -------------- | --------------------------- | ---------: | ---------- |
| `U1`           | DIP-20 ソケット 300mil       |          1 | **手はんだ** |
| `J1`           | 2 ピンヘッダ 2.54mm（+5V/GND） |          1 | **手はんだ** |
| `D1`–`D20`     | LED 0603                    | 最大 18    | JLCPCB     |
| `R1`–`R20`     | `Rled` 4.7kΩ 0603           | 最大 18    | JLCPCB     |
| `R21`–`R40`    | `Rd` 1kΩ 0603               | 最大 18    | JLCPCB     |
| `SW1`–`SW5`    | SPDT スイッチ（4 連 × 5 等） | 18 ポジション | JLCPCB  |
| `C1`           | 100nF 0603                  |          1 | JLCPCB     |

SMD 実装点数は最大約 61。**抵抗を 4 素子アレイにまとめると 36 → 9 個に減り、合計約 34 点**になる（→ REQUIREMENTS §5）。LCSC の Basic 部品で揃うかを Phase 1 で確認する。

抵抗値は `Rled` と `Rd` の 2 種類のみ。部品種類を増やさないこと。

## 4. リファレンス指定子の命名規則

生成スクリプトが機械的に参照できるよう、**ソケット接点番号 k（1〜20）と 1 対 1 に対応させる**:

| 部品         | Ref     |
| ------------ | ------- |
| LED          | `Dk`    |
| `Rled`       | `Rk`    |
| `Rd`         | `R(20+k)` |
| ソケット接点 | `U1` パッド `k` |

例: 接点 7 → `D7` / `R7` / `R27` / `U1` パッド 7。

この規則を崩すと型番別生成（電源接点の差し替えと DNP 指定）が成立しないため、**手作業で振り直さないこと**。

## 5. 寸法・レイアウト規約

| 項目               | 値                                       |
| ------------------ | ---------------------------------------- |
| 外形               | 33 × 50 mm                               |
| 層数 / 厚み / 銅箔 | 2 層 / 1.6mm / 1oz                       |
| 最小パターン幅     | 0.25mm（JLCPCB 下限 0.127mm には張り付かない） |
| 基板端クリアランス | 銅箔は端から 0.5mm 以上（V-cut 分離のため） |
| 実装面             | **上面のみ**（Economic 組立の制約）      |
| `U1` 配置          | タイル中央。ピン 1 が上、シルクで明示     |
| `C1` 配置          | `U1` の電源パッド直近                     |
| I/O セル配置       | 接点 k の LED / 抵抗 / スイッチを接点の直近に、接点順で並べる |

I/O セルは接点順に規則的に並べる。これにより自動配線が不要になり（→ REQUIREMENTS §9 R5）、シルクのピン名とも視覚的に対応する。

## 6. 型番別の生成規則

### 6.1 接点マッピング

n ピン IC をピン 1 側へ端寄せして挿入する前提:

```text
IC pin i  (i <= n/2)  ->  ソケット接点 i
IC pin i  (i >  n/2)  ->  ソケット接点 i + (20 - n)
```

### 6.2 差分の適用

| 差分         | 規則                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| ① 電源接点   | 型番の VCC / GND ピンを §6.1 で接点に変換し、その接点を +5V / GND ベタに接続。**I/O セルは実装しない** |
| ② 未実装セル | 使わない接点（n < 20 のとき中央の 20−n 接点）の `Dk` / `Rk` / `R(20+k)` を DNP とし、BOM・CPL から除外 |
| ③ シルク     | 汎用型番・機能名（EN / JP）・カテゴリ・各接点のピン名                                    |

### 6.3 実装セル数

| パッケージ | 実装する I/O セル |
| ---------- | ----------------: |
| DIP-14     | 12                |
| DIP-16     | 14                |
| DIP-20     | 18                |

### 6.4 電源ピンが非標準の型番

[`../REQUIREMENTS.md`](../REQUIREMENTS.md) §2.5 の 4 型番（74x73 / 74x75 / 74x90 / 74x93）は VCC/GND が角ピンにない。生成時に**一次資料で個別確認**すること。角ピン決め打ちのロジックを書かない。

---

## 7. 設計上の禁止事項

1. `Rd` の省略・470Ω 以下への変更（§2.2 の安全規則）
2. §4 のリファレンス命名規則を崩すこと
3. 抵抗値を 2 種類より増やすこと
4. 裏面への SMD 部品配置（Economic 組立は上面のみ）
5. 電源ピン位置を「角ピン」と決め打ちすること（§6.4）
6. 一次資料で VCC/GND を確認していない型番のタイルを発注対象に入れること
