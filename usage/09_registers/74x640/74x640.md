# 74x640 — Octal bus transceiver, inverting, 3-state outputs

- **カテゴリ**: `09_registers`
- **機能（EN）**: Octal bus transceiver, inverting, 3-state outputs
- **機能（JP）**: 8ビットバストランシーバ（反転、3状態出力）
- **レア度**: `Rare`

## 東芝 `TC74HC640AP`（DIP-20）

東芝のデータシート §6 に、完全型番 `TC74HC640AP` のパッケージ刻印例として **`74HC640AP`** が掲載されています。刻印は完全型番の略記で、末尾 `AP` のDIP-20を指します。同じ資料の `TC74HC640AF` はSOP-20です。

2本の8ビットバス間でデータを非同期に転送します。方向は DIR、切り離しは /G で指定し、転送時は各ビットが反転します。レジスタやシフトレジスタではありません。
