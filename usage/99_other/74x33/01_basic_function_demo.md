# 74x33 NORバッファ（オープンコレクタ） 基本動作デモ

> この資料はサンプル回路の解説です。**電気特性・最大定格・入力閾値などは必ず一次資料（データシート）で確認**してください。

## 回路概要

所持している `74x33` 系ICのうち、`SN74ALS33AN`（DIP想定）を使って、最小構成で基本動作を確認する回路です。

オープンコレクタ出力のNORゲートバッファです。入力A・Bが両方Lのとき出力がプルアップ抵抗でH、それ以外はLになります。

## 回路の仕様

- **電源**: +5V（一次資料で確認）
- **入力**: 手動（DIPスイッチ/タクトスイッチ）
- **出力**: LED表示（電流制限抵抗を必ず直列に接続）

## 接続方法

### 入力

- **入力（A, B）**: DIPスイッチまたはジャンパでH/Lを設定

### 出力

- **出力（Y）**: **プルアップ抵抗（4.7kΩ〜10kΩ）をVCCと出力ピン間に接続し、LED＋抵抗で出力状態を観測**

## 配線の要点

- **電源（VCC/GND）**: ピン表で確認した電源ピンに接続。0.1µFのデカップリングコンデンサをIC直近に配置。
- **入力のフローティング禁止**: 未使用入力は必ずVCCまたはGNDに接続。

### 注意事項

- **オープンコレクタ出力必須**: プルアップ抵抗なしで使用すると出力が浮きます。必ず4.7kΩ〜10kΩをVCC〜出力間に接続。
- **ワイヤードOR**: 複数ICの出力を直結してワイヤードOR（負論理AND）として使用できます（プルアップ1本で共有）。
- **ALS（高速版）**: 74ALSは従来の74LS/74Sより高速で低消費電流。電源デカップリングは特に重要です。
