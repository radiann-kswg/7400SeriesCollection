# 74x244 基本動作デモ（1回路）

> この資料はサンプル回路の解説です。**電気特性・最大定格・入力閾値などは必ず一次資料で確認**してください。

## 回路概要

所持している `74x244` 系ICのうち、`SN74HC244N`（DIP想定）を使って、最小構成で基本動作を確認する回路です。

- スイッチ入力（またはジャンパ）で入力を切り替え
- LEDで出力を観測

## 回路の仕様

- **電源**: +5V（ロジックファミリにより範囲が異なるため一次資料で確認）
- **入力**: 手動（DIPスイッチ/タクト）
- **出力**: LED表示（抵抗を必ず直列に）

## 配線の要点

- **VCC/GND**: ピン表で確認した電源ピンに接続。0.1µFをIC直近に配置。
- **入力**: スイッチでH/Lを切り替え（フローティング禁止）。
- **出力**: LED＋抵抗で観測（出力ドライブ能力は一次資料で確認）。

### 注意点
