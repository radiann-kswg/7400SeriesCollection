# 74x141 を使った 4 ビットバイナリ →BCD→ ニキシー管表示回路

## 回路概要

4 ビット 2 進数（0 ～ 15）を入力として受け取り、BCD 変換を経てニキシー管で 10 進数表示する回路です。2 桁のニキシー管を使用し、0 ～ 15 を「00」～「15」として表示します。バイナリデータを BCD に変換するアルゴリズムを論理回路で実装します。

## 回路の仕様

- **入力**: 4 ビット 2 進数（0000 ～ 1111、0 ～ 15）
- **出力**: 2 桁 10 進数表示（00 ～ 15）
- **変換方式**: 組み合わせ論理回路によるバイナリ →BCD 変換
- **表示方式**: 静的点灯（2 桁独立駆動）

## ピンアサインと配線方法

### バイナリ入力定義

```
入力ビット:
  I3 (MSB) ----+
  I2           |  4ビット2進数
  I1           |  (0～15)
  I0 (LSB) ----+
```

### バイナリ →BCD 変換ロジック

4 ビット 2 進数を 2 桁 BCD（8 ビット）に変換する論理式:

**10 の位 BCD (T3, T2, T1, T0)**:

```
T3 = 0  (常に0、範囲が0～15のため)
T2 = 0  (常に0)
T1 = I3  (8以上の場合に1)
T0 = I3  (8以上の場合に1)

簡略化:
  10の位 = "1" if (I3 == 1) else "0"
```

**1 の位 BCD (O3, O2, O1, O0)**:

```
O3 = I3 AND (NOT I2) AND (NOT I1)
O2 = I2 XOR I3
O1 = I1
O0 = I0
```

### 論理回路実装

**10 の位用 BCD 生成（固定値）**:

```
74x141(10の位) D (pin 12) ---- I3 (入力ビット3)
74x141(10の位) C (pin 13) ---- GND (常に0)
74x141(10の位) B (pin 14) ---- GND (常に0)
74x141(10の位) A (pin 15) ---- GND (常に0)

結果: I3=1なら表示「1」、I3=0なら表示「0」
```

**1 の位用 BCD 生成（組み合わせ論理）**:

O3 の生成:

```
I3 --+-- 74x04 (インバータ) --|
     |                        |
I2 --+-- 74x04 (インバータ) --+-- 74x00 (NAND) -- O3
     |                        |
I1 --+-- 74x04 (インバータ) --|
```

O2 の生成:

```
I3 ---+
      |--- 74x86 (XOR) --- O2
I2 ---+
```

O1, O0 の生成:

```
I1 ---- O1 (直接接続)
I0 ---- O0 (直接接続)
```

**74x141(1 の位)への接続**:

```
O3 ---- 74x141(1の位) D (pin 12)
O2 ---- 74x141(1の位) C (pin 13)
O1 ---- 74x141(1の位) B (pin 14)
O0 ---- 74x141(1の位) A (pin 15)
```

### 入力回路（DIP スイッチ）

```
[+5V]
  |
  +----- [DIPスイッチ I3] ---- I3
  |   |
  |   +-- [10kΩ] --- [GND]
  |
  +----- [DIPスイッチ I2] ---- I2
  |   |
  |   +-- [10kΩ] --- [GND]
  |
  +----- [DIPスイッチ I1] ---- I1
  |   |
  |   +-- [10kΩ] --- [GND]
  |
  +----- [DIPスイッチ I0] ---- I0
      |
      +-- [10kΩ] --- [GND]
```

## 配線の注意事項

### 論理回路の配線順序

1. まず入力バッファとして 74x04 を配置
2. 組み合わせ論理回路（74x86, 74x08 等）を実装
3. 最後に 74x141 に接続

### 信号の遅延対策

- 組み合わせ論理回路では信号経路により遅延が異なる
- グリッチが気になる場合、74x373 (ラッチ) で出力を同期させる
- 静的表示の場合は通常問題なし

### 簡略化実装の代替案

上記の完全な論理回路実装は複雑なため、以下の簡略版も可能:

**簡略版: 8,9 の表示を諦める（0 ～ 7 のみ）**

```
10の位 = 全て GND (常に0表示)
1の位 = 入力4ビットをそのまま74x141に接続
```

**簡略版 2: LUT ベース（ROM 使用）**

- 74x188 (256-bit PROM) 等を使用（未所持）
- 4 ビット入力 →8 ビット出力のルックアップテーブルを実装

## 表示器の対応について

### ニキシー管（BCD/冷陰極表示器）

- **最適**: 74x141 の本来の用途
- **表示範囲**: 00 ～ 15（10 進数）
- **動作電圧**: 170V、各桁 2 ～ 3mA
- **推奨管**: IN-12, IN-14

### LED 表示

- **代替可能**: ただし回路の改造が必要
- 74x141 の代わりに 74x42 (BCD-10 進デコーダ) を使用
- 各出力に LED + 電流制限抵抗を接続

### 7 セグメント LED 表示

- **不適合**: 74x141 は 7 セグメント用ではありません
- BCD→7 セグメント変換には 74x47 を使用

## 動作電源の概要

### ロジック電源

- **電圧**: +5V (±5%)
- **電流**: 約 150mA（74x141×2 + 論理ゲート IC×5）
- **推奨電源**: 500mA 以上の安定化電源

### ニキシー管駆動電源

- **電圧**: +170V ～ 180V（DC）
- **電流**: 20mA 以下（2 桁同時点灯時）
- **推奨電源**: DC-DC コンバータ

## 動作確認手順

### 初期確認

1. 論理回路の配線を段階的に確認
2. DIP スイッチを全て OFF (0000) に設定
3. 高電圧部分の絶縁を確認

### 通電テスト

1. +5V 電源を投入
2. 論理ゲート IC が発熱していないか確認
3. +170V 電源を投入
4. 両ニキシー管が「00」を表示することを確認

### 論理テスト

以下の入力パターンで表示を確認:

| I3  | I2  | I1  | I0  | 2 進 | 10 進 | 10 の位 | 1 の位 |
| --- | --- | --- | --- | ---- | ----- | ------- | ------ |
| 0   | 0   | 0   | 0   | 0000 | 0     | 0       | 0      |
| 0   | 0   | 0   | 1   | 0001 | 1     | 0       | 1      |
| 0   | 1   | 0   | 1   | 0101 | 5     | 0       | 5      |
| 0   | 1   | 1   | 1   | 0111 | 7     | 0       | 7      |
| 1   | 0   | 0   | 0   | 1000 | 8     | 1       | 0      |
| 1   | 0   | 0   | 1   | 1001 | 9     | 1       | 1      |
| 1   | 0   | 1   | 0   | 1010 | 10    | 1       | 2      |
| 1   | 1   | 1   | 1   | 1111 | 15    | 1       | 7      |

**注意**: 上記の 1 の位表示は論理式実装によります。簡略版では異なる場合があります。

## トラブルシューティング

### 1 の位が正しく表示されない

- 組み合わせ論理回路の配線ミスを確認
- 特に XOR、AND、NAND ゲートの入出力を再チェック

### 8 以上で 10 の位が点灯しない

- I3 信号が 74x141(10 の位) D 端子に接続されているか確認
- 配線の断線をチェック

### 全体的に表示がおかしい

- 各論理ゲートの電源（+5V、GND）を確認
- デカップリングコンデンサの配置を確認

## 回路の拡張性について

### 8 ビット（0 ～ 255）以上への拡張, Double-Dabble アルゴリズム実装

- 8 ビット入力を 3 桁 BCD (百の位、十の位、一の位) に変換
- 8 ビット以上の変換には、ダブルダブル（Double-Dabble）アルゴリズムが有効
- シフトレジスタ（74x164, 74x165）と加算器（74x83）を組み合わせ、BCD 変換回路を構築
- 複雑度が高いため、別途専用設計ドキュメントが必要
- **詳細な実装例**: [06_8bit_binary_to_bcd_converter.md](./06_8bit_binary_to_bcd_converter.md) を参照

### 16 進数表示への対応

- BCD 変換を行わず、直接 16 進数として表示
- 0 ～ 9 はニキシー管、A ～ F は別途 LED 等で表示
- または、16 進数対応のニキシー管（ZM1350 等、未所持）を使用

### マイコンインタフェース

- 論理回路の代わりに、Arduino でバイナリ →BCD 変換を行う
- 変換結果を 74x373 (ラッチ) に出力し、74x141 で表示
- ソフトウェアで柔軟な変換処理が可能

### 実用的な代替案

本回路は教育・学習目的としては有用ですが、実用的には:

- マイコン（Arduino 等）で BCD 変換を行う方が簡単
- 専用 IC（74x184, 74x185 等、未所持）を使用する
- FPGA で変換回路を実装する

などの方法が一般的です。
