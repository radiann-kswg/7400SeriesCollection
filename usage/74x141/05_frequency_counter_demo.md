# 74x141 を用いた周波数表示デモ回路

## 回路概要

74x141 とカウンタを組み合わせ、入力信号の周波数を測定して 1 桁のニキシー管に表示する簡易周波数カウンタです。0 ～ 9Hz の低周波信号測定に特化しており、ゲート時間 1 秒で正確な周波数を表示します。

## 回路の仕様

- **測定範囲**: 0 ～ 9Hz（0 ～ 9 回/秒）
- **ゲート時間**: 1 秒（固定）
- **表示桁数**: 1 桁
- **測定精度**: ±1 カウント（ゲート時間による誤差）
- **入力信号**: TTL 互換レベル（0V ～ 5V）

## ピンアサインと配線方法

### 基本構成ブロック図

```
[入力信号] → [74x132整形] → [74x163カウンタ] → [74x173ラッチ] → [74x141] → [ニキシー管]
                                      ↑                    ↑
                                    [ゲート信号]        [ラッチ信号]
                                      ↓
                            [74x161タイマー] ← [1Hzクロック]
```

### 1Hz タイムベース生成（簡易版）

水晶発振器がない場合、NE555 を使用:

```
NE555アストエーブルモード設定:
  R1 = 680kΩ
  R2 = 680kΩ
  C  = 1μF

  周波数 f = 1.44 / ((R1 + 2*R2) * C)
           ≈ 1.44 / (2.04MΩ * 1μF)
           ≈ 0.7Hz

  可変抵抗で1.0Hzに調整
```

### 1 秒ゲート時間生成（74x161 使用）

1Hz クロックを基準に、1 秒間のゲート信号を生成:

```
        74x161 (ゲートタイマー)
        +---v---+
  /LOAD -|1    16|- VCC (+5V)
   CLK -|2    15|- RC (未使用)
    P0 -|3    14|- Q0
    P1 -|4    13|- Q1
    P2 -|5    12|- Q2
    P3 -|6    11|- Q3
   CEP -|7    10|- CET
   GND -|8     9|- /PE
        +-------+

1Hz CLK → pin 2
Q0 (pin 14) → 74x74 (FFでゲート信号生成)

動作:
- 1秒間カウント: 0→1→0（2カウントで1サイクル）
- Q0立ち上がりでゲート開始
- Q0立ち下がりでゲート終了 & ラッチ
```

### 周波数カウンタ（74x163）

```
        74x163 (周波数カウンタ)
        +---v---+
  /LOAD -|1    16|- VCC (+5V)
   CLK -|2    15|- RC (未使用)
    P0 -|3    14|- Q0 → 74x173 D0
    P1 -|4    13|- Q1 → 74x173 D1
    P2 -|5    12|- Q2 → 74x173 D2
    P3 -|6    11|- Q3 → 74x173 D3
   CEP -|7    10|- CET → +5V
   GND -|8     9|- /PE
        +-------+

入力信号 (74x132整形後) → pin 2 (CLK)
ゲート信号 → pin 7 (CEP, イネーブル制御)
```

### 10 進リセット回路

74x163 は 0 ～ 15 までカウントするため、10 でリセット:

```
Q3 (pin 11) ---|
               |--- 74x00 NAND → インバータ → /LOAD (pin 1)
Q1 (pin 13) ---|

理由: 10進数「10」= 2進数「1010」= Q3=1, Q1=1
```

### 表示ラッチ（74x173）

測定値をラッチして、次の測定中も表示を保持:

```
        74x173 (4ビット3ステートレジスタ)
        +---v---+
    M  -|1    16|- VCC (+5V)
    N  -|2    15|- 1Q → 74x141 A (pin 15)
   1D  -|3    14|- 2Q → 74x141 B (pin 14)
   2D  -|4    13|- 3Q → 74x141 C (pin 13)
   3D  -|5    12|- 4Q → 74x141 D (pin 12)
   4D  -|6    11|- CLK (ラッチクロック)
   /OE -|7    10|- CLR (クリア、+5Vに接続)
   GND -|8     9|- G1/G2 (GND接続でラッチ有効)
        +-------+

74x163 Q0～Q3 → 74x173 1D～4D (pin 3～6)
ゲート終了パルス → CLK (pin 11)
/OE (pin 7) → GND（常時出力有効）
```

### ゲート制御とラッチ信号生成

```
[1Hz CLK] → 74x161 Q0 → 74x74 (D-FF) → ゲート信号 → 74x163 CEP
                              |
                              +--(立下りエッジ検出)-→ ラッチ信号 → 74x173 CLK
```

74x74 の使用:

- D-FF #1: ゲート信号の生成（1 秒間 HIGH）
- D-FF #2: ラッチパルスの生成（ゲート終了時にパルス）

### 入力信号整形（74x132）

外部信号を TTL レベルに整形し、ノイズ除去:

```
[入力信号] → 74x132 (シュミットトリガNAND) → 74x163 CLK

シュミットトリガの効果:
- ヒステリシス特性により、緩やかな立ち上がり/立ち下がり信号を整形
- チャタリングやノイズを除去
```

## 配線の注意事項

### ゲート信号のタイミング

- ゲート信号は正確に 1 秒間 HIGH でなければならない
- 1Hz クロックの精度が測定精度を決定
- 水晶発振器 + 分周回路を推奨（高精度が必要な場合）

### ラッチタイミング

- ゲート終了時（1 秒経過時）に 74x173 へラッチ信号を送る
- ラッチ信号は短いパルス（立ち上がりエッジ）
- ラッチ後、74x163 はリセットされて次の測定を開始

### 10 進リセットのタイミング

- 74x163 が「10」を出力した瞬間にリセット
- 0 ～ 9 の範囲でカウントするため、BCD 変換不要

### 入力信号の条件

- 電圧範囲: 0V ～ 5V（TTL レベル）
- 周波数: 0 ～ 9Hz（本回路の測定上限）
- デューティ比: 特に制約なし（エッジ検出のため）

## 表示器の対応について

### ニキシー管（BCD/冷陰極表示器）

- **最適**: 周波数の瞬時値を視覚的に表示
- **推奨管**: IN-14 (中型)、視認性が良い
- **輝度**: 電流制限抵抗 15kΩ で適切な明るさ

### LED 表示

- **可能**: 74x141 を 74x42 に変更し、LED バーグラフで表示
- 10 個の LED で 0 ～ 9 を表現
- 電流制限抵抗を各 LED に追加

### 7 セグメント LED 表示

- **不適合**: 74x141 は 7 セグメント用ではない
- 代わりに 74x47 を使用すれば 7 セグメントで表示可能

## 動作電源の概要

### ロジック電源

- **電圧**: +5V (±5%)
- **電流**: 約 100mA（全 IC 合計）
- **推奨電源**: 安定化電源、300mA 以上

### ニキシー管駆動電源

- **電圧**: +170V ～ 180V（DC）
- **電流**: 5mA 以下（1 桁表示）
- **推奨電源**: DC-DC コンバータ（5V→170V）

## 動作確認手順

### タイムベース確認

1. 1Hz クロック信号をオシロスコープで確認
2. 周期が 1.00 秒（± 数 ms 以内）であることを確認
3. NE555 を使用する場合、可変抵抗で微調整

### ゲート信号確認

1. 74x74 のゲート信号出力をオシロスコープで確認
2. 1 秒間 HIGH を維持し、次の 1 秒間 LOW になることを確認
3. タイミングがずれている場合、74x161 の接続を確認

### カウンタ動作確認

1. 入力信号として、既知の周波数（例: 5Hz）を入力
2. ニキシー管に「5」が表示されることを確認
3. 1 秒ごとに表示が更新されることを確認

### 測定精度確認

1. 関数発生器などで正確な周波数を入力
2. 複数回測定して誤差を確認
3. ±1 カウント以内であれば正常

## トラブルシューティング

### 表示がちらつく

- 74x173 のラッチが正しく動作していない
- ラッチ信号のタイミングを確認
- /OE (pin 7) が GND に接続されているか確認

### 表示が常に 0 または 9

- 入力信号が来ていない、または測定範囲外
- 入力信号レベルを確認（0V ～ 5V）
- 74x132 の整形回路を確認

### 1 秒ごとに更新されない

- 1Hz クロックの周波数を確認
- 74x161 の接続を確認
- ゲート信号が 1 秒間正確に HIGH か確認

### カウントが 10 以上に進む

- 10 進リセット回路（74x00 での Q3 と Q1 の検出）を確認
- /LOAD 信号が正しくアクティブになっているか確認

## 回路の拡張性について

### 測定範囲の拡張（0 ～ 99Hz）

- 74x163 と 74x141 をもう 1 セット追加して 2 桁表示
- 上位桁用にキャリー信号を接続
- 0 ～ 99Hz の測定が可能

### 測定範囲の拡張（0 ～ 999Hz、3 桁）

- さらに 1 桁追加して 3 桁表示
- 0 ～ 999Hz の測定範囲
- 桁数に応じてゲート時間を 0.1 秒に短縮することも検討

### 高周波数測定（kHz 以上）

- プリスケーラ（分周器）を入力段に追加
- 1/10、1/100、1/1000 の分周比を切替可能に
- 表示に単位（Hz, kHz）の表示を追加

### 周期測定モード

- 逆数を取ることで、周波数ではなく周期を表示
- 低周波数（1Hz 以下）の測定に有効

### 最大値/最小値ホールド

- 74x85 (比較器) を追加
- 測定値を常に比較し、最大値または最小値を保持
- 変動する信号のピーク周波数を測定

### オートレンジ機能

- 測定値に応じて、自動的にゲート時間や分周比を変更
- より広い周波数範囲を 1 つの回路で測定

## 応用例

### 回転数計（タコメータ）

- 入力信号をホール素子やフォトインタラプタで検出
- モーターの回転数（rpm）を表示
- 適切な分周比を設定

### 脈拍計

- フォトセンサで指先の血流を検出
- 心拍数（bpm）を表示
- 測定範囲: 0 ～ 9bpm は低すぎるため、10 倍表示に変更

### 振り子の周期測定

- 光センサで振り子の通過を検出
- 周期を周波数として表示
- 物理実験の教材として有用

### 信号発生器のモニタ

- 自作発振器の出力周波数を監視
- リアルタイムで周波数を確認しながら調整

## 設計上のヒント

### 測定精度の向上

測定精度は主にゲート時間とタイムベースクロックの精度に依存します:

- **ゲート時間を長くする**: 1 秒 →10 秒にすることで、1/10 の誤差に低減
- **高精度タイムベース**: 水晶発振器（1MHz）を分周して 1Hz を生成
- **温度補償**: TCXO（Temperature Compensated Crystal Oscillator）を使用

### ノイズ対策

- 入力信号ラインをツイストペアまたはシールドケーブルで配線
- 電源ラインにフェライトビーズを挿入
- 各 IC の電源ピン近傍にデカップリングコンデンサ

### 周波数範囲と桁数の関係

| 桁数 | 測定範囲    | ゲート時間 | 精度 |
| ---- | ----------- | ---------- | ---- |
| 1 桁 | 0 ～ 9Hz    | 1 秒       | ±1Hz |
| 2 桁 | 0 ～ 99Hz   | 1 秒       | ±1Hz |
| 3 桁 | 0 ～ 999Hz  | 1 秒       | ±1Hz |
| 4 桁 | 0 ～ 9999Hz | 1 秒       | ±1Hz |

ゲート時間を 10 秒にすれば、精度は ±0.1Hz に向上しますが、測定更新レートが遅くなります。

### 実用的な測定範囲

本回路（1 桁、0 ～ 9Hz）は教育用デモやオーディオ周波数帯の超低域測定に適しています。実用的な周波数カウンタとしては、少なくとも 3 桁（0 ～ 999Hz）以上を推奨します。
