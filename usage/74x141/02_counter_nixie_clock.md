# 74x141 を使った 2 桁カウンタ式ニキシー管時計回路

## 回路概要

74x141 を 2 個使用し、74x90 (10 進カウンタ) と組み合わせることで、00 ～ 99 までカウント表示する 2 桁ニキシー管表示回路を構築します。クロック信号により自動カウントアップし、簡易的な秒カウンタやタイマーとして動作します。

## 回路の仕様

- **表示桁数**: 2 桁（10 の位、1 の位）
- **カウント範囲**: 00 ～ 99（循環）
- **駆動方式**: 静的点灯（各桁独立駆動）
- **クロック入力**: 外部発振器、または手動パルス
- **リセット機能**: マニュアルリセット（全桁 0 クリア）

## ピンアサインと配線方法

### 74x90 (10 進カウンタ) 基本接続

```
        74x90 (1の位)              74x90 (10の位)
        +---v---+                  +---v---+
  CLK -|1 CKB 14|- NC        CO1 -|1 CKB 14|- NC
      -|2  R1 13|- NC            -|2  R1 13|- NC
      -|3  R2 12|- QA            -|3  R2 12|- QA
   NC -|4  NC 11|- QD            -|4  NC 11|- QD
  VCC -|5 VCC 10|- GND         VCC -|5 VCC 10|- GND
      -|6  R9 9 |- QB            -|6  R9 9 |- QB
      -|7  R8 8 |- QC            -|7  R8 8 |- QC
        +-------+                  +-------+
         (1の位)                    (10の位)
```

### カウンタ接続図

```
[CLK入力] ----+---- 74x90(1の位) pin 14 (CKA)
              |
              |     74x90(1の位) QD (pin 11) ---- 74x90(10の位) pin 14 (CKA)
              |     (桁上がり信号)
              |
              +---- 74x132 (デバウンス回路経由)

[リセットSW] -+---- 74x132 (デバウンス) ---- 両74x90の R9(1), R9(2) ピンへ
```

### 74x141 への接続

**1 の位用**:

```
74x90(1の位) QA (pin 12) ---- 74x141(1の位) A (pin 15)
74x90(1の位) QB (pin 9)  ---- 74x141(1の位) B (pin 14)
74x90(1の位) QC (pin 8)  ---- 74x141(1の位) C (pin 13)
74x90(1の位) QD (pin 11) ---- 74x141(1の位) D (pin 12)
```

**10 の位用**:

```
74x90(10の位) QA (pin 12) ---- 74x141(10の位) A (pin 15)
74x90(10の位) QB (pin 9)  ---- 74x141(10の位) B (pin 14)
74x90(10の位) QC (pin 8)  ---- 74x141(10の位) C (pin 13)
74x90(10の位) QD (pin 11) ---- 74x141(10の位) D (pin 12)
```

### リセット回路（74x132 使用）

```
[+5V]
  |
  +--[10kΩ]--- [タクトSW] --- [GND]
        |
        +------ 74x132 pin 1 (入力A)
        |
        +--[0.1μF]--- [GND]  (デバウンス)

74x132 pin 2 (入力B) ---- +5V
74x132 pin 3 (出力) ----- 両74x90の R9(1), R9(2) ピンへ
```

### クロック発振回路（NE555 使用、1Hz）

```
[+5V]
  |
  +---- NE555 pin 8 (VCC)
  |
  +--[470kΩ]--- NE555 pin 7 (DISCHARGE)
  |       |
  |       +--[680kΩ]--- NE555 pin 6 (THRESHOLD)
  |                |
  |                +--- NE555 pin 2 (TRIGGER)
  |                |
  |             [1μF] --- GND
  |
  +---- NE555 pin 4 (RESET, プルアップ)

NE555 pin 3 (OUTPUT) ---- 74x90(1の位) CLK入力
NE555 pin 1 (GND) ------- GND
```

## 配線の注意事項

### カウンタのリセット配線

- 74x90 のリセットピン R9(1) と R9(2) を両方 High にすると、カウンタは 0 にクリア
- リセット信号は 74x132 でデバウンス処理を行い、チャタリングを防止

### 桁上がり信号

- 74x90 の QD 出力 (pin 11) が "9→0" 遷移時にパルスを出力
- このパルスを 10 の位のクロック入力に接続することで桁上がりを実現

### 74x90 の内部接続

- 74x90 は内部で ÷2 と ÷5 の 2 つのカウンタを持つ
- 10 進カウンタとして使用する場合、QA (pin 12) を CKB (pin 1) に接続する必要がある場合あり
- 使用する 74x90 の型番（SN74LS90N）のデータシートで内部接続を確認

### クロック入力の安定化

- 手動パルス入力の場合は、必ず 74x132 (シュミットトリガ) でデバウンス
- 発振回路使用時も、信号にノイズが乗る場合は 74x132 を通すことを推奨

## 表示器の対応について

### ニキシー管（BCD/冷陰極表示器）

- **最適**: 2 桁独立駆動のため、各桁が常時点灯
- **輝度**: 均一で安定した表示
- **動作電圧**: 170V、各桁 2 ～ 3mA
- **推奨管**: IN-12 (小型)、IN-14 (中型)、IN-18 (大型)

### LED 表示

- **代替可能**: ただし 74x141 本来の設計意図から外れる
- 各 74x141 出力にプルアップ抵抗 (10kΩ) を接続し、+5V へ
- LED 表示用には 74x42 + 74x47 の組み合わせの方が適切

### 7 セグメント LED 表示

- **不適合**: 74x141 は 7 セグメント用ではありません
- 7 セグメント表示には 74x47 (所持: SN74LS47N) を使用

## 動作電源の概要

### ロジック電源

- **電圧**: +5V (±5%)
- **電流**: 約 100mA（74x90×2 + 74x141×2 + 74x132）
- **推奨電源**: 500mA 以上の安定化電源

### ニキシー管駆動電源

- **電圧**: +170V ～ 180V（DC）
- **電流**: 20mA 以下（2 桁同時点灯時）
- **推奨電源**: 50mA 以上の DC-DC コンバータ

### 発振回路電源（NE555 使用時）

- **電圧**: +5V（ロジック電源と共用可）
- **電流**: 追加で約 10mA

## 動作確認手順

### 初期確認

1. 全配線を確認（特に高電圧部分）
2. 74x90 の内部接続が正しいか確認
3. リセットスイッチを OFF、クロック入力を停止

### 通電テスト

1. +5V 電源のみ投入
2. リセットスイッチを押下 → 両 74x90 が 0 にクリア
3. +170V 電源を投入
4. 両ニキシー管が「0」を表示することを確認

### カウント動作テスト

1. クロック入力を手動で与える（タクトスイッチまたはジャンパ線）
2. 1 の位が 0→1→2→...→9→0 とカウントアップすることを確認
3. 1 の位が 9→0 遷移時に、10 の位が +1 されることを確認

### 自動カウントテスト（NE555 使用時）

1. NE555 発振回路を接続
2. 約 1 秒ごとにカウントアップすることを確認
3. 99 まで到達後、00 に戻ることを確認

## トラブルシューティング

### カウントが進まない

- クロック信号が 74x90 に到達しているか確認（オシロスコープ推奨）
- 74x90 のリセットピンが GND（Low）になっているか確認
- 74x90 の内部接続（÷2 と ÷5 の接続）を確認

### 桁上がりしない

- 1 の位 74x90 の QD 出力が 10 の位のクロック入力に接続されているか確認
- 配線の接続不良をチェック

### 数字が飛ぶ、不規則にカウント

- クロック入力にチャタリングが発生している可能性
- 74x132 デバウンス回路を確認、コンデンサ値を増やす（0.1μF → 1μF）

### リセットが効かない

- 74x90 の R9(1) と R9(2) 両方に信号が届いているか確認
- 74x132 の出力が High レベルになっているか確認

## 回路の拡張性について

### 4 桁・6 桁表示への拡張

- 74x141 と 74x90 を追加することで、任意の桁数に拡張可能
- 時計（時:分:秒）表示の場合、6 桁必要（74x141×6、74x90×6）

### 60 進カウンタへの改造（時計用）

- 10 の位が「5」に達したら次の桁へキャリーするロジックを追加
- 74x85 (比較器) で値を監視し、「59→00」遷移を制御

### ダイナミック駆動への変更

- 消費電力削減のため、桁を高速切り替えて表示
- 74x138 (デコーダ) + トランジスタスイッチで桁選択回路を追加
- ニキシー管のアノード側に PNP トランジスタを挿入

### アラーム機能の追加

- 74x85 (マグニチュードコンパレータ、所持: 未入手) で設定値と比較
- 一致時にブザーや LED を駆動

### RTC（リアルタイムクロック）との接続

- DS3231 等の RTC モジュールを接続
- I2C 通信で時刻データを取得し、BCD 形式で 74x141 に入力
- この場合は 74x90 の代わりに 74x373 (ラッチ) を使用

## 設計上の注意点

### 静的駆動の消費電力

- 2 桁常時点灯のため、ニキシー管の消費電力は約 5mA (170V × 2 桁 × 2.5mA)
- 長時間使用時は発熱に注意

### カウンタのグリッチ対策

- 74x90 の BCD 出力は遷移時に一瞬グリッチが発生する可能性
- 74x373 (ラッチ) を追加してグリッチをマスクすることを推奨（上級者向け）

### ニキシー管の寿命対策

- 同じ数字を長時間表示すると、陰極焼付きが発生
- 定期的に全数字を表示させるアンチ・ポイズニング・ルーチンを推奨
