# 74x181/182 簡易 CPU アキュムレータ回路

## 回路概要

74S181 を中心に、74HC273(レジスタ)、74HC139(デコーダ)を組み合わせて構成する
簡易的な CPU アキュムレータ回路です。累積演算や連続演算が可能な実用的なシステムです。

## 回路の仕様

### 主要機能

- 4 ビットアキュムレータレジスタ (A)
- 4 ビット汎用レジスタ (B)
- 16 種類の算術・論理演算
- クロック同期動作による段階的演算
- アキュムレータへの結果自動格納

### 動作サイクル

1. **ロードサイクル**: A/B レジスタへのデータ書き込み
2. **演算サイクル**: ALU による演算実行
3. **ストアサイクル**: 演算結果をアキュムレータへ格納
4. **読み出し**: 現在のアキュムレータ値を LED 表示

### アーキテクチャ

```
[入力スイッチ] → [データバス:4bit]
                    ↓
      [74HC273 レジスタA] ← (アキュムレータ)
                    ↓
              [74S181 ALU]
                    ↓
      [74HC273 レジスタB] ← (汎用レジスタ)
                    ↓
              [結果バス:4bit] → [LED表示]
                    ↓
      [フィードバック → レジスタA]
```

## ピンアサインと配線方法

### システムブロック図

```
    +--------+
    | DIPスイッチ |  (データ入力 D0-D3)
    +--------+
         |
    +----+----+----+
    |    |    |    |
    v    v    v    v
  +----------------+
  | 74HC139        | (レジスタ選択デコーダ)
  | SEL0,SEL1      |
  +----------------+
    |         |
    WR_A      WR_B (書き込み信号)
    |         |
    v         v
  +---------+ +---------+
  |74HC273  | |74HC273  | (レジスタA/B)
  |Reg A    | |Reg B    |
  +---------+ +---------+
    |           |
    A0-A3       B0-B3
    |           |
    +-----+-----+
          |
      +--------+
      |74S181  | (ALU)
      | F0-F3  |
      +--------+
          |
       [LED表示]
          |
     (フィードバック)
```

### 74HC273 アキュムレータレジスタ (IC1) 配線

```
（一次資料: datasheets/_download/TI(TexasInstruments)/SN74HC/SN74HC273.PDF の "Pin Functions" より）

         +-----+_+-----+
   CLR -|1          20|- VCC
    Q1 -|2          19|- Q8
    D1 -|3          18|- D8
    D2 -|4          17|- D7
    Q2 -|5          16|- Q7
    Q3 -|6          15|- Q6
    D3 -|7          14|- D6
    D4 -|8          13|- D5
    Q4 -|9          12|- Q5
   GND -|10         11|- CLK
         +-----------+

※この回路では下位4ビット（1〜4）だけ使用。

- 74HC273(IC1)の D入力（下位4bit）
  - D0相当=1D: ピン3
  - D1相当=2D: ピン4
  - D2相当=3D: ピン7
  - D3相当=4D: ピン8
- 74HC273(IC1)の Q出力（下位4bit）
  - Q0相当=1Q: ピン2
  - Q1相当=2Q: ピン5
  - Q2相当=3Q: ピン6
  - Q3相当=4Q: ピン9
- CLK: ピン11
- CLR（アクティブLow）: ピン1
- GND: ピン10 / VCC: ピン20

フィードバック経路（例）:
- 74S181 F0(ピン9) → (74HC157使用時はIC5 1B:ピン3) → 74HC273(IC1) 1D(ピン3)
- 74HC273(IC1) 1Q(ピン2) → 74S181 A0(ピン2)
```

### 74HC273 汎用レジスタ B (IC2) 配線

```
（一次資料: datasheets/_download/TI(TexasInstruments)/SN74HC/SN74HC273.PDF の "Pin Functions" より）

※この回路では下位4ビット（1〜4）だけ使用。

- 74HC273(IC2)の D入力（下位4bit）
  - 1D: ピン3
  - 2D: ピン4
  - 3D: ピン7
  - 4D: ピン8
- 74HC273(IC2)の Q出力（下位4bit）
  - 1Q: ピン2
  - 2Q: ピン5
  - 3Q: ピン6
  - 4Q: ピン9
- CLK: ピン11
- CLR（アクティブLow）: ピン1
```

### 74S181 ALU (IC3) 配線

```
ピン2  (A0) ← レジスタA出力 Q0
ピン23 (A1) ← レジスタA出力 Q1
ピン21 (A2) ← レジスタA出力 Q2
ピン19 (A3) ← レジスタA出力 Q3

ピン1  (B0) ← レジスタB出力 Q0
ピン22 (B1) ← レジスタB出力 Q1
ピン20 (B2) ← レジスタB出力 Q2
ピン18 (B3) ← レジスタB出力 Q3

ピン6-3 (S0-S3) ← 機能選択スイッチ
ピン8  (M) ← モード選択スイッチ
ピン7  (Cn) ← キャリー入力スイッチ

ピン9,10,11,13 (F0-F3) → LED表示 & レジスタAのD入力 (フィードバック)
ピン16 (Cn+4) → LED表示
```

### 74HC139 デコーダ/セレクタ制御 (IC4) 配線

```
         +-----+_+-----+
   1E  -|1          16|- VCC
   1A0 -|2          15|- 2E
   1A1 -|3          14|- 2A0
   1Y0 -|4          13|- 2A1
   1Y1 -|5          12|- 2Y0
   1Y2 -|6          11|- 2Y1
   1Y3 -|7          10|- 2Y2
   GND -|8           9|- 2Y3
         +-----------+

ピン1  (1E) ← 書き込みイネーブル (プッシュボタン、通常H)
ピン2,3 (1A0,1A1) ← レジスタ選択スイッチ (2bit)
  00: レジスタA書き込み
  01: レジスタB書き込み
  10: 演算実行(結果→A)
  11: 未使用

（一次資料: datasheets/_download/PHILIPS(NXPSemiconductors)/74HC139.PDF の "PIN DESCRIPTION" より）

重要:
- 1E/2E はアクティブLow（Lで有効）
- 1Y0〜1Y3 / 2Y0〜2Y3 もアクティブLow
- 74HC273 は「CLK(ピン11)の立上り」でラッチするため、74HC139の出力をそのままCLKへ直結しないこと

この文書では 74HC139 の出力を「選択線（アクティブLow）」として扱う:
- ピン4  (1Y0) = WR_A_n（レジスタA書き込み選択）
- ピン5  (1Y1) = WR_B_n（レジスタB書き込み選択）
- ピン6  (1Y2) = EXEC_n（演算結果をAへ取り込む選択）

※WR_A_n/WR_B_n/EXEC_n から 74HC273 のCLK(ピン11)へは、別途「正のクロックパルス」を作るゲート回路（例: NAND/AND等）を介して接続してください。
```

### （オプション）74HC157 2:1 セレクタ（IC5）でレジスタA入力を切り替える

レジスタA(IC1)の D入力（ピン3/4/7/8）に「データスイッチ」か「ALU出力」を選択して入れる場合、74HC157 を 4bit 分だけ使う。

（一次資料: datasheets/_download/TI(TexasInstruments)/SN74HC/SN74HC157.PDF の "Pin Functions" より）

制御ピン:
- A/B（選択）: ピン1
- G（出力ストローブ、アクティブLow）: ピン15
- GND: ピン8 / VCC: ピン16

4ビット分の配線（A側=データスイッチ、B側=ALU出力の例）:
- bit0
  - 1A(ピン2)  ← DATA0
  - 1B(ピン3)  ← ALU_F0（74S181 ピン9）
  - 1Y(ピン4)  → RegA 1D（74HC273(IC1) ピン3）
- bit1
  - 2A(ピン5)  ← DATA1
  - 2B(ピン6)  ← ALU_F1（74S181 ピン10）
  - 2Y(ピン7)  → RegA 2D（74HC273(IC1) ピン4）
- bit2
  - 3A(ピン11) ← DATA2
  - 3B(ピン10) ← ALU_F2（74S181 ピン11）
  - 3Y(ピン9)  → RegA 3D（74HC273(IC1) ピン7）
- bit3
  - 4A(ピン14) ← DATA3
  - 4B(ピン13) ← ALU_F3（74S181 ピン13）
  - 4Y(ピン12) → RegA 4D（74HC273(IC1) ピン8）

## 使用方法

### 初期設定

1. リセットスイッチを押してレジスタ A, B をクリア
2. レジスタ選択を"00"(レジスタ A)に設定
3. データスイッチで初期値を設定
4. 書き込みボタンを押してレジスタ A に格納

### 基本的な演算手順

#### 例 1: 累積加算 (A = A + B)

```
1. レジスタAに初期値5を設定
   - 選択: 00, データ: 0101, 書き込みCLK
2. レジスタBに加算値3を設定
   - 選択: 01, データ: 0011, 書き込みCLK
3. 機能選択を"加算"(S=1001, M=L, Cn=H)に設定
4. レジスタ選択を"10"(演算実行)に変更
5. クロックを入力 → A = 8 (1000)
6. Bを2に変更 (0010)
7. クロック入力 → A = 10 (1010)
```

#### 例 2: 減算演算 (A = A - B)

```
1. レジスタAに10を設定 (1010)
2. レジスタBに3を設定 (0011)
3. 機能選択を"減算"(S=0110, M=L, Cn=H)に設定
4. 演算実行 → A = 7 (0111)
```

#### 例 3: 論理 AND 演算

```
1. レジスタAに1100を設定
2. レジスタBに1010を設定
3. 機能選択を"AND"(S=1011, M=H)に設定
4. 演算実行 → A = 1000
```

### 連続演算プログラム例

#### カウントアップ (A = A + 1)

```
初期設定: A=0, B=1
ループ:
  1. S=1001, M=L, Cn=H (加算)
  2. クロック入力
  → A: 0→1→2→3→...→15→0 (4ビットオーバーフロー)
```

#### 累乗計算 (A = A \* 2)

```
S=1001, M=L (A+A, シフト左と同等)
A=1 → 2 → 4 → 8 → 16(0) → ...
```

## 配線の注意事項

### クロック信号の処理

- **チャタリング対策**: プッシュスイッチに 0.1μF コンデンサと 10kΩ 抵抗で RC フィルタ
- **クロック分配**: 各レジスタへの配線は等長に（±2cm 以内）
- **代替案**: 74HC14 シュミットトリガでクリーンなクロック生成

### データバスの配線

- 4 本のデータ線(D0-D3)は並行して配線
- クロストークを避けるため、隣接配線との間隔を 3mm 以上確保
- 長距離配線(30cm 超)の場合は 74HC245 等でバッファリング

### フィードバックループの安定化

- ALU 出力 → レジスタ A 入力の配線は短く(10cm 以内)
- セレクタ IC でフィードバックを制御し、不要時は切断
- 74HC273 のセットアップ時間(20ns)を考慮

### 電源とリセット

- **パワーオンリセット**: 電源投入時に自動リセット回路を推奨
  - 構成: 10kΩ + 10μF + ダイオードによるパワーオンリセット
- **手動リセット**: プッシュボタン + プルアップ抵抗
- **電源デカップリング**: 各 IC 直近に 0.1μF 配置(4 個)

## 必要な部品リスト

### 汎用ロジック IC

- **74S181** (4 ビット ALU): 1 個
- **74HC273** (8 ビット D フリップフロップ): 2 個 ※実際には 4bit のみ使用
- **74HC139** (デュアル 2-4 デコーダ): 1 個
- **オプション**: 74HC157 (クアッド 2-1 セレクタ): 1 個 (データソース切替用)

### 電子部品

- **DIP スイッチ**:
  - データ入力: 4bit×1 組
  - レジスタ選択: 2bit×1 組
  - 機能選択: 4bit×1 組
  - モード/キャリー: 1bit×2 個
  - 合計: 12 個
- **プッシュボタンスイッチ**: 3 個 (クロック、リセット、書き込み)
- **プルダウン抵抗 10kΩ**: 12 個
- **プルアップ抵抗 10kΩ**: 3 個 (ボタン用)
- **LED**: 6 個 (結果 4+キャリー 1+状態 1)
- **電流制限抵抗 330Ω**: 6 個
- **セラミックコンデンサ 0.1μF**: 4 個 (各 IC 用)
- **コンデンサ 10μF**: 1 個 (パワーオンリセット用)
- **ダイオード 1N4148**: 1 個 (リセット回路用)
- **ブレッドボード**: 大型サイズ 1 枚
- **ジャンパーワイヤ**: 適量
- **電源**: 5V (400mA 以上)

## 表示器の対応

### LED 表示

- **対応**: ◎ 完全対応
- **表示内容**:
  - F0-F3: 演算結果/アキュムレータ値 (4bit)
  - Cn+4: キャリー出力
  - STATE: 演算実行中を示すステータス LED
- **色分け推奨**: 結果(緑)、キャリー(赤)、ステータス(黄)

### 7 セグメント LED 表示

- **対応**: ○ 追加回路で対応可能
- **必要 IC**: 74HC47×1 個
- **接続**: アキュムレータ出力(Q0-Q3) → 74HC47 → 7 セグ
- **表示範囲**: 0-9 は正確、10-15 は簡易表示
- **利点**: 演算結果を 10 進数で直感的に確認可能

### BCD/ニキシー管表示

- **対応**: △ 4 ビット範囲内(0-9)なら可能
- **必要 IC**:
  - 74HC141 (BCD-デシマルデコーダ): 1 個
  - または 74LS145 (同等品)
- **接続**: アキュムレータ出力 → 74HC141 → ニキシー管
- **制約**:
  - 10-15 の値は表示不可(BCD 外)
  - 演算結果を 0-9 に制限する必要あり
  - 高電圧電源(170V)が別途必要
- **推奨**: 簡易デモには不向き、LED or 7 セグ推奨

4. 動作開始

## 回路の拡張性

### 機能拡張案

#### 1. 8 ビットアキュムレータ化

- **追加 IC**: 74S181×1 個、74S182×1 個、74HC273×2 個
- **機能**: 8 ビット演算、より複雑な計算が可能
- **詳細**: `02_8bit_alu_with_lookahead.md` の構成を統合

#### 2. プログラムカウンタの追加

- **追加 IC**: 74HC161×1 個 (4 ビットカウンタ)
- **機能**: 命令アドレス管理、簡易プログラム実行
- **接続**: カウンタ出力 → アドレスバス → 命令メモリ

#### 3. 命令メモリの実装

- **追加 IC**: 27C64 EPROM または 28C64 EEPROM
- **機能**: プログラム格納、自動演算シーケンス実行
- **容量**: 8KB (簡易 CPU としては十分)

#### 4. 状態マシンの追加

- **追加 IC**: 74HC161×2 個、74HC138×1 個
- **機能**: フェッチ/デコード/実行サイクルの自動制御
- **実現**: 簡易的な CPU 命令サイクル

#### 5. 外部入出力ポート

- **追加 IC**: 74HC245×1 個 (双方向バスドライバ)
- **機能**: 外部デバイスとのデータ交換
- **用途**: センサー入力、モーター制御等

### プログラム実行例

#### カウントアップループ

```
初期化:
  A = 0
  B = 1
  S = 1001 (加算)
  M = L

ループ:
  CLK → A = A + B
  (繰り返し)
```

#### 階乗計算 (4 ビット範囲)

```
A = 1 (結果)
B = 2 (乗数)
S = 1001 (加算、実際にはA+A=2A)

※正確な乗算には複数サイクル必要
```
