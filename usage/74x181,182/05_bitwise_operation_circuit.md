# 74x181 高速ビット演算回路

## 回路概要

74S181 の論理演算機能に特化した高速ビット演算回路です。
デジタル信号処理、マスク演算、ビットパターン生成などの用途に最適化されています。

## 回路の仕様

### 主要機能

- 4 ビットビット単位論理演算（AND, OR, XOR, NAND 等）
- マスクパターン生成と適用
- ビットパターン変換（反転、交換、挿入）
- 高速パターンマッチング（25ns 以下）
- 連続ビット演算のパイプライン処理

### 対応演算

| 演算  | S3-S0 | M   | 用途             |
| ----- | ----- | --- | ---------------- |
| AND   | 1011  | H   | ビットマスク     |
| OR    | 1110  | H   | ビット結合       |
| XOR   | 0110  | H   | ビット反転、比較 |
| NAND  | 0100  | H   | 否定マスク       |
| NOR   | 0001  | H   | 全ビット検査     |
| NOT A | 0000  | H   | ビット反転       |
| XNOR  | 1001  | H   | ビット一致検出   |
| PASS  | 1111  | H   | バッファ         |

### 性能指標

- **演算速度**: 25ns (74S181 の Schottky 特性)
- **スループット**: 40MHz (パイプライン構成時)
- **レイテンシ**: 1 クロック (レジスタ含む)

## ピンアサインと配線方法

### システムブロック図

```
[パターン入力] → [74HC574 入力レジスタ]
                        ↓
[マスク入力]   → [74S181 ビット演算]
                        ↓
               [74HC574 出力レジスタ]
                        ↓
               [LED/外部出力]
                        ↓
               [74HC86 XORゲート] (パリティ生成)
```

### 74HC574 入力レジスタ A (IC1) 配線

```
         +-----+_+-----+
   /OE -|1          20|- VCC
    D0 -|2          19|- Q0
    D1 -|3          18|- Q1
    D2 -|4          17|- Q2
    D3 -|5          16|- Q3
    D4 -|6          15|- Q4
    D5 -|7          14|- Q5
    D6 -|8          13|- Q6
    D7 -|9          12|- Q7
   GND -|10         11|- CLK
         +-----------+

ピン2-5 (D0-D3) ← DIPスイッチ入力 (パターンA)
ピン11 (CLK) ← クロック入力 (プッシュボタン)
ピン1  (/OE) ← GND (常時出力イネーブル)
ピン19-16 (Q0-Q3) → 74S181の A入力
```

### 74HC574 入力レジスタ B (IC2) 配線

```
ピン2-5 (D0-D3) ← DIPスイッチ入力 (マスク/パターンB)
ピン11 (CLK) ← クロック入力 (IC1と共通)
ピン1  (/OE) ← GND
ピン19-16 (Q0-Q3) → 74S181の B入力
```

### 74S181 ビット演算コア (IC3) 配線

```
ピン2,23,21,10 (A0-A3) ← 入力レジスタA (IC1出力)
ピン1,24,13,11 (B0-B3) ← 入力レジスタB (IC2出力)
ピン6-3 (S0-S3) ← 演算選択DIPスイッチ
ピン8  (M) ← H (論理演算モード固定)
ピン7  (Cn) ← GND (未使用、論理演算では無関係)
ピン16-19 (F0-F3) → 出力レジスタ (IC4入力)
```

### 74HC574 出力レジスタ (IC4) 配線

```
ピン2-5 (D0-D3) ← 74S181の F出力
ピン11 (CLK) ← クロック入力 (遅延クロック、オプション)
ピン1  (/OE) ← 出力イネーブルスイッチ (通常L)
ピン19-16 (Q0-Q3) → LED表示 & 外部出力端子
```

### 74HC86 パリティジェネレータ (IC5) 配線

```
         +-----+_+-----+
   1A  -|1          14|- VCC
   1B  -|2          13|- 4B
   1Y  -|3          12|- 4A
   2A  -|4          11|- 4Y
   2B  -|5          10|- 3B
   2Y  -|6           9|- 3A
   GND -|7           8|- 3Y
         +-----------+

ピン1,2   (1A,1B) ← F0, F1
ピン3     (1Y) → 中間XOR結果
ピン4,5   (2A,2B) ← F2, F3
ピン6     (2Y) → 中間XOR結果
ピン9,10  (3A,3B) ← 1Y, 2Y (中間結果)
ピン8     (3Y) → パリティ出力LED
```

## 使用方法

### 基本的なビット演算

#### マスク演算（特定ビットの抽出）

```
目的: 入力データの下位2ビットのみ抽出
手順:
  1. S3-S0 = 1011 (AND演算)
  2. パターンA = 1101 (入力データ)
  3. マスク   B = 0011 (下位2ビットマスク)
  4. CLK入力
  5. 結果F = 0001 (下位2ビットのみ)
```

#### ビット反転

```
目的: 特定ビットの反転
手順:
  1. S3-S0 = 0110 (XOR演算)
  2. パターンA = 1010 (入力データ)
  3. マスク   B = 1111 (全ビット反転)
  4. CLK入力
  5. 結果F = 0101 (全ビット反転)

  または
  3. マスク   B = 0101 (特定ビット反転)
  4. CLK入力
  5. 結果F = 1111 (指定ビットのみ反転)
```

#### パターンマッチング（一致検出）

```
目的: パターンの一致をチェック
手順:
  1. S3-S0 = 1001 (XNOR演算)
  2. パターンA = 1010 (入力データ)
  3. 基準    B = 1010 (比較パターン)
  4. CLK入力
  5. 結果F = 1111 (全ビット一致)
     パリティLED = L (偶数個の1)

  不一致時:
  3. 基準    B = 0101
  5. 結果F = 0000 (全ビット不一致)
```

### 連続ビット処理

#### シリアルデータのパターン検出

```
手順:
  1. S3-S0 = 1001 (XNOR)
  2. 基準パターンBを設定 (例: 1010)
  3. データストリームを順次A入力
     データ1: 1010 → F=1111 (一致検出)
     データ2: 0101 → F=0000 (不一致)
     データ3: 1010 → F=1111 (一致検出)
  4. 一致時にパリティLEDでトリガー
```

#### ビットスワップ（ビット順序入れ替え）

```
74S181単体では不可
→ 複数の74S181と74HC157(マルチプレクサ)を組み合わせて実現
```

### 高度な応用

#### 4 ビットパターン生成器

```
構成: 74HC161(カウンタ) + 74S181(演算)
動作:
  1. カウンタで0-15を生成
  2. カウンタ出力 → 74S181のA入力
  3. マスクB = 固定パターン
  4. S選択で演算を変更
  → 複雑なビットパターン生成
```

## 配線の注意事項

### クロック信号の同期

- 入力レジスタと出力レジスタのクロックタイミング調整
- **推奨**: 出力レジスタは入力より 5ns 遅延させる（伝搬遅延考慮）
- **方法**: 74HC14 で遅延クロック生成、または直接同期

### 高速動作のための配線

- **配線長**: ALU 周辺は 5cm 以内
- **グラウンドプレーン**: 信号リターンパスを短く
- **電源デカップリング**: 各 IC 直近に 0.1μF + 10μF 並列
- **信号完全性**: 配線インピーダンスを考慮（50Ω 推奨）

### 論理演算モード固定化

- 74S181 の M ピンは常に H (VCC に直結)
- Cn ピンはグラウンド接続（論理演算では無関係だが安定化のため）

### パリティ回路の精度

- 74HC86 の XOR 段数を増やす場合、伝搬遅延を考慮
- 3 段 XOR: 約 15ns 遅延
- 高速動作時は 74F86 等の高速版使用を推奨

## 必要な部品リスト

### 汎用ロジック IC

- **74S181** (4 ビット ALU): 1 個
- **74HC574** (8 ビット D フリップフロップ): 3 個 ※4bit のみ使用
- **74HC86** (クアッド XOR ゲート): 1 個
- **オプション**: 74HC161 (カウンタ、連続パターン生成用)

### スイッチ・入力部品

- **DIP スイッチ**: 4bit×2 組 + 4bit×1 組(演算選択) = 12 個
- **プッシュボタン**: 2 個 (クロック、リセット)
- **プルダウン抵抗 10kΩ**: 12 個
- **プルアップ抵抗 10kΩ**: 2 個

### LED 表示

- **LED**: 6 個 (結果 4bit + パリティ + ステータス)
- **電流制限抵抗 330Ω**: 6 個

### 電子部品

- **セラミックコンデンサ 0.1μF**: 5 個
- **セラミックコンデンサ 10μF**: 5 個 (大容量デカップリング)
- **ブレッドボード**: 標準サイズ 1 枚
- **ジャンパーワイヤ**: 適量
- **電源**: 5V (350mA 以上)

## 表示器の対応

### LED 表示

- **対応**: ◎ 完全対応
- **推奨配置**:
  - ビットパターン: 横一列配置
  - パリティ: 独立した色(黄色)で配置
  - ステータス: 演算実行中を緑色で表示

### 7 セグメント LED 表示

- **対応**: △ 可能だが意義は低い
- **理由**: ビット演算結果は 2 進表示が直感的
- **代替**: 16 進 1 桁表示なら 74HC47 で対応可能

### BCD/ニキシー管表示

- **対応**: × 不適
- **理由**: ビット演算は 2 進表現が本質的に重要

### ロジックアナライザ接続

- **対応**: ◎ 推奨
- **接続**: 出力レジスタ → ロジアナ入力
- **利点**:
  - 波形観測で高速動作を確認
  - パターン解析が容易
  - タイミング検証が可能
- **推奨機器**:
  - Saleae Logic 8
  - DSLogic Plus
  - Arduino + Simple Logic Analyzer

## 動作電源

### 標準電源仕様

- **電圧**: 5V ±0.25V
- **電流**: 350mA 以上推奨
- **推奨電源**: AC アダプタ (5V 500mA)

### 消費電力内訳

- **74S181**: 約 180mA
- **74HC574×3**: 約 15mA
- **74HC86**: 約 5mA
- **LED×6**: 約 120mA
- **合計**: 約 320mA

### 高速動作時の注意

- スイッチング時の突入電流を考慮
- 電源ライン全体に 100μF 電解コンデンサ配置
- 各 IC 直近に 0.1μF + 10μF 並列配置

## 回路の拡張性

### 機能拡張案

#### 1. 8 ビットビット演算への拡張

- **追加 IC**: 74S181×1 個、74HC574×3 個
- **機能**: 8 ビットパターンのビット演算
- **接続**: 2 つの 74S181 を並列動作（独立演算）

#### 2. ルックアップテーブル(LUT)実装

- **追加 IC**: 27C64 EPROM または SRAM
- **機能**: 複雑なビット変換テーブルの実装
- **接続**: 入力レジスタ → アドレス → EPROM → 出力レジスタ
- **用途**: ビットリバース、グレイコード変換等

#### 3. パターン自動生成モード

- **追加 IC**: 74HC161×1 個、74HC4060×1 個
- **機能**: 連続的なビットパターン生成
- **用途**: テストパターン生成、信号生成器

#### 4. ビット演算プロセッサ

- **追加 IC**: 74HC273×2 個、74HC139×1 個、EPROM
- **機能**: マイクロコードによるビット演算シーケンス実行
- **用途**: 簡易ビット演算専用プロセッサ

#### 5. シリアル ⇔ パラレル変換

- **追加 IC**: 74HC595×1 個、74HC165×1 個
- **機能**: シリアルビットストリームのパラレル演算
- **用途**: 通信データの処理、プロトコル変換
