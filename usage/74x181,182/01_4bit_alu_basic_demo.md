# 74x181 4 ビット ALU 基本動作デモ回路

## 回路概要

74S181 を使用した 4 ビット算術論理演算装置(ALU)の基本動作を確認するための実演回路です。
手動スイッチによる入力と、LED 表示による結果確認を行います。

## 回路の仕様

### 主要機能

- 4 ビットデータ A と B に対する算術・論理演算
- 16 種類の演算機能の切り替え
- キャリー入力/出力の制御と表示
- A=B 比較機能の確認

### 動作モード

- **論理演算モード** (M=H): AND, OR, XOR, NAND 等の論理演算
- **算術演算モード** (M=L): 加算、減算、インクリメント等の算術演算

## ピンアサインと配線方法

### 74S181 ピン配置 (24 ピン DIP)

```
         +-----+_+-----+
    B0 -|1          24|- VCC (5V)
    A0 -|2          23|- Cn+4 (キャリー出力)
    S3 -|3          22|- G (キャリー生成)
    S2 -|4          21|- P (キャリー伝搬)
    S1 -|5          20|- A=B (比較出力)
    S0 -|6          19|- F3 (結果bit3)
    Cn -|7          18|- F2 (結果bit2)
     M -|8          17|- F1 (結果bit1)
    F0 -|9          16|- F0 (結果bit0)
    A3 -|10         15|- B3
    B3 -|11         14|- A2
   GND -|12         13|- B2
         +-----------+
```

### 入力回路

1. **データ A 入力 (A0-A3)**: 4 個の DIP スイッチ + 10kΩ プルダウン抵抗
2. **データ B 入力 (B0-B3)**: 4 個の DIP スイッチ + 10kΩ プルダウン抵抗
3. **機能選択 (S0-S3)**: 4 個の DIP スイッチ + 10kΩ プルダウン抵抗
4. **モード選択 (M)**: トグルスイッチ + 10kΩ プルダウン抵抗
5. **キャリー入力 (Cn)**: トグルスイッチ + 10kΩ プルダウン抵抗

### 出力回路

1. **演算結果 (F0-F3)**: 4 個の LED + 330Ω 電流制限抵抗
2. **キャリー出力 (Cn+4)**: 1 個の LED + 330Ω 電流制限抵抗
3. **A=B 出力**: 1 個の LED + 330Ω 電流制限抵抗
4. **キャリー生成 (G)**: 1 個の LED + 330Ω 電流制限抵抗 (オプション)
5. **キャリー伝搬 (P)**: 1 個の LED + 330Ω 電流制限抵抗 (オプション)

### 基本配線

```
[入力スイッチ] → [10kΩ] → GND
                ↓
              74S181入力ピン
                ↓
            74S181出力ピン
                ↓
            [330Ω] → LED → GND
```

## 使用方法

### 基本操作手順

1. 電源投入前に全スイッチを OFF(L)にする
2. 5V 電源を接続
3. モード選択スイッチ(M)で算術/論理を選択
4. 機能選択スイッチ(S0-S3)で演算機能を設定
5. データ A、B を入力
6. LED で演算結果を確認

### 代表的な演算例

#### 加算演算 (M=L, S3-S0=1001)

```
A=0101 (5), B=0011 (3), Cn=H
→ F=1000 (8), Cn+4=L
```

#### 減算演算 (M=L, S3-S0=0110, Cn=H)

```
A=0101 (5), B=0011 (3)
→ F=0010 (2), Cn+4=H
```

#### AND 演算 (M=H, S3-S0=1011)

```
A=1100, B=1010
→ F=1000
```

#### OR 演算 (M=H, S3-S0=1110)

```
A=1100, B=1010
→ F=1110
```

## 配線の注意事項

### 電源とグラウンド

- **74S181 の消費電流**: 最大 180mA (Schottky TTL)
- **電源デカップリング**: VCC-GND 間に 0.1μF セラミックコンデンサを配置（IC 直近）
- **電源容量**: 5V 300mA 以上推奨

### 信号の取り扱い

- **未使用入力**: 必ずプルダウン抵抗で GND に落とす（フローティング厳禁）
- **出力駆動**: 74S シリーズは HC/HCT シリーズとの直接接続可能
- **配線長**: 高速信号のため、できるだけ短く（10cm 以内推奨）

### TTL レベル注意

- **入力 H**: 2.0V 以上
- **入力 L**: 0.8V 以下
- **出力 H**: 2.7V 以上 (IOH=-1mA 時)
- **出力 L**: 0.5V 以下 (IOL=20mA 時)

## 必要な部品リスト

### 汎用ロジック IC

- **74S181** (4 ビット ALU): 1 個

### 電子部品

- **DIP スイッチ**: 4bit×3 組 + 1bit×2 個 = 14 個
- **プルダウン抵抗 10kΩ**: 14 個
- **LED** (赤色推奨): 8 個（結果 4+キャリー 1+A=B1+G1+P1）
- **電流制限抵抗 330Ω**: 8 個
- **セラミックコンデンサ 0.1μF**: 1 個（電源デカップリング用）
- **ブレッドボード**: 標準サイズ 1 枚
- **ジャンパーワイヤ**: 適量
- **電源**: 5V (300mA 以上)

## 表示器の対応

### LED 表示

- **対応**: ◎ 完全対応（本回路の標準構成）
- **接続**: 各出力ピン → 330Ω → LED(アノード-カソード) → GND
- **利点**: 部品点数が少なく、配線が簡単
- **推奨 LED**: 赤色 or 緑色 (VF=1.8-2.2V, IF=10-20mA)

### 7 セグメント LED 表示

- **対応**: △ 可能だが追加 IC が必要
- **必要 IC**: 74HC138 (3-8 デコーダ) または 74HC47 (BCD デコーダ)
- **注意**: 74S181 の 4 ビット出力を直接 7 セグに接続不可
- **推奨構成**: F0-F3 → 74HC47 → 7 セグ (共通カソード)
- **制約**: 10 進数表示は 0-9 のみ、A-F は正しく表示されない

### BCD/ニキシー管表示

- **対応**: × 直接接続不可
- **理由**: 74S181 は 4 ビットバイナリ出力、BCD ではない
- **代替案 1**: F0-F3 をマイコンで読み取り、BCD 変換後に 74HC141 等で駆動
- **代替案 2**: 演算結果を BCD 補正回路(74x184 等)で変換後に表示
- **注意**: 本回路の範囲外、大幅な回路追加が必要

## 動作電源

### 標準電源仕様

- **電圧**: 5V ±0.25V (4.75-5.25V)
- **電流**: 300mA 以上推奨
- **推奨電源**: AC アダプタ (5V 500mA 以上)

### 消費電力内訳

- **74S181**: 最大 180mA (全出力 H 時)
- **LED×8**: 約 160mA (20mA×8 個)
- **合計**: 約 340mA (最大時)

### 電源オプション

1. **USB バスパワー**: 5V 500mA 対応（推奨）
2. **AC アダプタ**: 5V 1A 出力（安定性高）
3. **乾電池**: 単 3×4 本(6V) + LDO レギュレータ(5V)
4. **ベンチ電源**: 5V 500mA 設定

### 電源投入シーケンス

1. 全スイッチを OFF 状態にする
2. 電源を投入
3. 0.1 秒待機
4. スイッチ操作開始

## 回路の拡張性

### 機能拡張案

#### 1. クロック動作モード追加

- **追加 IC**: 74HC161 (カウンタ)、74HC273 (レジスタ)
- **機能**: 自動カウント演算、連続演算モード
- **配線**: 161 出力 → 273 入力 → 181 入力

#### 2. 8 ビット ALU への拡張

- **追加 IC**: 74S181×1 個、74S182×1 個
- **機能**: 8 ビット演算、高速キャリー伝搬
- **詳細**: `02_8bit_alu_with_lookahead.md` 参照

#### 3. 演算結果の保存機能

- **追加 IC**: 74HC574 (8 ビットレジスタ)
- **機能**: 演算結果の一時保存、連続演算
- **配線**: 181 出力 → 574 入力、574 出力 → LED

#### 4. 16 進数表示機能

- **追加 IC**: 74HC47×1 個、7 セグ LED×1 個
- **機能**: 演算結果を 16 進 1 桁で表示
- **制約**: 0-9 は正しく表示、A-F は簡易表示

#### 5. マイコン連携モード

- **追加部品**: Arduino/ESP32
- **機能**: シリアル通信で演算指令、結果ログ記録
- **配線**: 181 出力 → マイコン GPIO 入力

### 互換性情報

- **74LS181 への置き換え**: 可能（消費電流減少、速度低下）
- **74HC181 への置き換え**: 不可（DIP24 ピンの 74HC181 は存在しない）
- **74F181 への置き換え**: 可能（消費電流やや減少）
