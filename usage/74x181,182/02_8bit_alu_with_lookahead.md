# 74x181/182 8 ビット ALU ルックアヘッド拡張回路

## 回路概要

74S181 を 2 個と 74S182 を使用して構成する 8 ビット算術論理演算装置(ALU)です。
74S182 のルックアヘッド・キャリー・ジェネレータにより、高速な 8 ビット演算を実現します。

## 回路の仕様

### 主要機能

- 8 ビットデータ A と B に対する算術・論理演算
- 16 種類の演算機能（4 ビット版と同一）
- 高速キャリー伝搬による演算速度向上
- 上位/下位 4 ビットの独立動作確認可能

### 性能指標

- **演算時間**: 約 25ns (74S181×2 + 74S182 のルックアヘッド動作)
- **4 ビット段間キャリー**: 約 12ns (74S182 による高速伝搬)
- **比較**: 74S181 のリップルキャリー(約 40ns)に対し約 40%高速化

### 動作モード

- **論理演算モード** (M=H): 8 ビット論理演算
- **算術演算モード** (M=L): 8 ビット加減算、インクリメント等

## ピンアサインと配線方法

### システムブロック図

```
  Carry In (Cn)
        |
        +-----------------------------+
        |                             |
  +-----+----+      G0,P0      +------+-----+
A0-A3 →|  74S181  |---------------→|  74S182     |
B0-B3 →| (下位)   |                | (lookahead) |
S0-S3 →|          |←---(共通)------|             |
   M  →|   F0-F3  |                |             |
  Cn  →|   Cn     |                |   Cn+x  Cn+y|→ Carry Out (8bit)
       +----------+                +---+-----+---+
               |     |
               |     +-- (任意) 予備/拡張
               |
               v
  +----------+      G1,P1      +----------+
A4-A7 →|  74S181  |---------------→|          |
B4-B7 →| (上位)   |                |          |
S0-S3 →|          |←---(共通)------|          |
   M  →|   F4-F7  |                |          |
 Cn+x →|   Cn     |                |          |
       +----------+                +----------+

※ ALU_L の Cn(ピン7) は Carry In と同一信号です。
   ALU_H の Cn(ピン7) は 74S182 の Cn+x 出力から供給します。
```

### 74S181 下位 4 ビット (IC1) 配線

```
ピン2  (A0) ← スイッチ入力 (A bit0)
ピン23 (A1) ← スイッチ入力 (A bit1)
ピン21 (A2) ← スイッチ入力 (A bit2)
ピン19 (A3) ← スイッチ入力 (A bit3)

ピン1  (B0) ← スイッチ入力 (B bit0)
ピン22 (B1) ← スイッチ入力 (B bit1)
ピン20 (B2) ← スイッチ入力 (B bit2)
ピン18 (B3) ← スイッチ入力 (B bit3)

ピン6-3 (S0-S3) ← 機能選択スイッチ (共通)
ピン8  (M) ← モード選択スイッチ (共通)
ピン7  (Cn) ← キャリー入力スイッチ (Carry In)

ピン9,10,11,13 (F0-F3) → LED表示 (結果下位)
ピン17 (G/Y) → 74S182の G0 入力
ピン15 (P/X) → 74S182の P0 入力
```

### 74S181 上位 4 ビット (IC2) 配線

```
ピン2  (A0) ← スイッチ入力 (A bit4)
ピン23 (A1) ← スイッチ入力 (A bit5)
ピン21 (A2) ← スイッチ入力 (A bit6)
ピン19 (A3) ← スイッチ入力 (A bit7)

ピン1  (B0) ← スイッチ入力 (B bit4)
ピン22 (B1) ← スイッチ入力 (B bit5)
ピン20 (B2) ← スイッチ入力 (B bit6)
ピン18 (B3) ← スイッチ入力 (B bit7)

ピン6-3 (S0-S3) ← 機能選択スイッチ (IC1と共通)
ピン8  (M) ← モード選択スイッチ (IC1と共通)
ピン7  (Cn) ← 74S182の Cn+x 出力

ピン9,10,11,13 (F0-F3) → LED表示 (結果上位、F4-F7として表示)
ピン17 (G/Y) → 74S182の G1 入力
```

### 74S182 ルックアヘッドキャリージェネレータ 配線

```
         +-----+_+-----+
    G1 -|1          16|- VCC (5V)
    P1 -|2          15|- G0
    G0 -|3          14|- P0
    P2 -|4          13|- Cn (Carry in)
    G2 -|5          12|- Cn+x
    P3 -|6          11|- Cn+y
    G3 -|7          10|- Cn+z
   GND -|8           9|- Cn+w
         +-----------+

実際の接続:
ピン15 (G0) ← 下位74S181の G/Y 出力 (ピン17)
ピン14 (P0) ← 下位74S181の P/X 出力 (ピン15)
ピン1  (G1) ← 上位74S181の G/Y 出力 (ピン17)
ピン2  (P1) ← 上位74S181の P/X 出力 (ピン15)
ピン13 (Cn) ← キャリー入力スイッチ (Carry In)
ピン12 (Cn+x) → 上位74S181の Cn 入力 (ピン7)
ピン11 (Cn+y) → LED表示 (8ビット全体のキャリー出力として使用)

※ 下位74S181の Cn(ピン7) は Carry In と直結してください。
```

## 使用方法

### 基本操作手順

1. 電源投入前に全スイッチを OFF
2. 5V 電源を接続
3. モード選択(M)で算術/論理を選択
4. 機能選択(S0-S3)で演算を設定
5. 8 ビットデータ A、B を入力
6. LED で 8 ビット演算結果を確認

### 代表的な演算例

#### 8 ビット加算 (M=L, S3-S0=1001)

```
A=01100101 (101), B=00110011 (51), Cn=H
→ F=10011000 (152), Cn+8=L
```

#### 8 ビット減算 (M=L, S3-S0=0110, Cn=H)

```
A=11001000 (200), B=01010000 (80)
→ F=01111000 (120), Cn+8=H
```

#### 8 ビット AND (M=H, S3-S0=1011)

```
A=11110000, B=10101010
→ F=10100000
```

### 高速動作の確認方法

1. オシロスコープで Cn+8 出力を観測
2. Cn 入力を HIGH→LOW に切り替え
3. 伝搬遅延が約 25ns 以内であることを確認
4. (参考) 74S181 リップルキャリーは約 40ns

## 配線の注意事項

### 電源とグラウンド

- **総消費電流**: 最大 450mA (74S181×2 + 74S182 + LED)
- **電源デカップリング**: 各 IC 直近に 0.1μF セラミックコンデンサ配置（3 個）
- **電源容量**: 5V 600mA 以上推奨

### キャリー信号配線の注意

- **G, P 信号**: 74S181 → 74S182 の配線は極力短く（5cm 以内）
- **キャリー出力信号**: 74S182 → 74S181(上位 Cn) の配線も短く（5cm 以内）
- **インピーダンス**: 高速信号のため、長配線時は 50Ω 終端を検討
- **グラウンドプレーン**: 可能であればグラウンド面を広く取る

### タイミング注意事項

- **セットアップ時間**: A, B, S, M 入力は安定してから 10ns 以上保持
- **ホールド時間**: 出力読み取り後、5ns 以上入力を保持
- **グリッチ**: 入力切り替え時に出力が一時的に不定になる（約 5ns）

### S0-S3, M 信号の配線

- 2 つの 74S181 に共通接続
- バッファリング不要（74S シリーズは駆動能力高い）
- 配線長が 30cm 以上の場合は 74HC244 等でバッファリング推奨

## 必要な部品リスト

### 汎用ロジック IC

- **74S181** (4 ビット ALU): 2 個
- **74S182** (ルックアヘッドキャリー): 1 個

### 電子部品

- **DIP スイッチ**: 4bit×4 組 + 1bit×2 個 = 18 個
- **プルダウン抵抗 10kΩ**: 18 個
- **LED**: 11 個（結果 8+キャリー 1+G1+P1）
- **電流制限抵抗 330Ω**: 11 個
- **セラミックコンデンサ 0.1μF**: 3 個（各 IC 用）
- **ブレッドボード**: 大型サイズ 1 枚（830 穴以上推奨）
- **ジャンパーワイヤ**: 適量
- **電源**: 5V (600mA 以上)

## 表示器の対応

### LED 表示

- **対応**: ◎ 完全対応（本回路の標準構成）
- **接続**: 各出力ピン → 330Ω → LED → GND
- **推奨配置**: 下位 4bit(緑)、上位 4bit(赤)で色分け推奨
- **追加表示**: Cn+8 キャリー出力は黄色 LED 推奨

### 7 セグメント LED 表示

- **対応**: △ 可能だが大幅な追加回路が必要
- **必要 IC**:
  - 74HC47×2 個 (上位/下位の 16 進変換用)
  - 74HC138×1 個 (10 以上の簡易表示用、オプション)
- **接続**: F0-F3 → 74HC47 → 7 セグ 1、F4-F7 → 74HC47 → 7 セグ 2
- **制約**: 各桁 0-9 のみ正確、A-F は簡易表示

### BCD/ニキシー管表示

- **対応**: × 直接接続不可
- **理由**: 8 ビットバイナリ出力、BCD 変換が必要
- **代替案**:
  1. バイナリ →BCD 変換 IC (74x184, 74x185) を追加
  2. マイコンでバイナリ →BCD 変換後、74HC141 で駆動
- **桁数**: 3 桁必要 (0-255 表示のため)
- **複雑度**: 回路規模が 2-3 倍に拡大

## 動作電源

### 標準電源仕様

- **電圧**: 5V ±0.25V (4.75-5.25V)
- **電流**: 600mA 以上推奨
- **推奨電源**: AC アダプタ (5V 1A)

### 消費電力内訳

- **74S181×2**: 最大 360mA
- **74S182**: 最大 50mA
- **LED×11**: 約 220mA
- **合計**: 約 630mA (最大時)

### 電源投入シーケンス

1. 全スイッチを OFF
2. 電源投入
3. 0.5 秒待機（電源安定化）
4. スイッチ操作開始

### 電源安定化対策

- 入力に 1000μF 電解コンデンサを並列接続推奨
- 各 IC 近傍に 0.1μF セラミック配置（必須）
- 電源配線は太く短く（AWG22 以上推奨）

## 回路の拡張性

### 機能拡張案

#### 1. 16 ビット ALU への拡張

- **追加 IC**: 74S181×2 個、74S182×1 個（計 4+2 構成）
- **接続**: 74S182 を 2 段カスケード接続
- **制約**: 74S182 は 2 個しか所持していないため、追加入手が必要

#### 2. 演算結果レジスタの追加

- **追加 IC**: 74HC574×1 個 (8 ビットレジスタ)
- **機能**: 演算結果の一時保存、連続演算が可能
- **配線**: F0-F7 → 574 D 入力、クロック信号で取り込み

#### 3. マルチプレクサによる入力切替

- **追加 IC**: 74HC157×2 個 (クアッド 2 入力マルチプレクサ)
- **機能**: 入力ソースの動的切替（スイッチ/レジスタ/外部）
- **用途**: 連続演算、累積加算など

#### 4. 7 セグ 2 桁表示の追加

- **追加 IC**: 74HC47×2 個、共通カソード 7 セグ ×2 個
- **機能**: 演算結果の 10 進/16 進表示
- **配線**: F0-F3 → 47(1) → 7seg(L), F4-F7 → 47(2) → 7seg(H)

#### 5. シリアル出力機能

- **追加 IC**: 74HC595×1 個 (シフトレジスタ)
- **機能**: 演算結果のシリアル出力、マイコン連携
- **配線**: F0-F7 → 595 パラレル入力、クロックでシフト出力

### 演算速度の比較

| 構成                    | キャリー伝搬時間 | 総演算時間 |
| ----------------------- | ---------------- | ---------- |
| 74S181 リップルキャリー | 約 40ns          | 約 50ns    |
| 74S181+74S182           | 約 12ns          | 約 25ns    |
| 速度向上                | 約 70%短縮       | 約 50%短縮 |

### 互換性情報

- **74LS181/182 への置き換え**: 可能（消費電流 1/3、速度約 2 倍低下）
- **74F181/182 への置き換え**: 可能（消費電流やや減、速度同等）
- **74AS181 への置き換え**: 可能（速度やや向上、182 は AS 版なし）
