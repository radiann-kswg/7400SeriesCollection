# 74x141 とカウンタを使ったルーレット表示デモ回路

## 回路概要

74x141 と 74x163 (4 ビットバイナリカウンタ) を組み合わせ、ニキシー管上で高速に数字がスクロールするルーレット風の表示デモを作成します。スタート/ストップボタンにより、ランダムな数字で停止する簡易ゲーム装置としても機能します。

## 回路の仕様

- **表示桁数**: 1 桁
- **表示範囲**: 0 ～ 9（循環）
- **動作モード**:
  - 高速カウントモード（約 100Hz）
  - スローカウントモード（約 1Hz）
  - 停止モード
- **制御**: スタート/ストップボタン、速度切替スイッチ

## ピンアサインと配線方法

### 74x163 カウンタの基本接続

```
        74x163 (4ビットカウンタ)
        +---v---+
  LOAD -|1    16|- VCC (+5V)
   CLK -|2    15|- RC (リップルキャリー、未使用)
    P0 -|3    14|- Q0
    P1 -|4    13|- Q1
    P2 -|5    12|- Q2
    P3 -|6    11|- Q3
   CEP -|7    10|- CET
   GND -|8     9|- PE (パラレルイネーブル、未使用)
        +-------+
```

### 10 進カウンタ化（0 ～ 9 循環）

74x163 は 0 ～ 15 までカウントするため、10 でリセットする回路を追加:

```
Q3, Q1 ---- 74x08 (AND) ---- LOAD (pin 1, アクティブLOW)
                             |
                             +--- 74x04 (インバータ経由でクリア)
```

理由: 10 進数の「10」= 2 進数「1010」= Q3=1, Q1=1
この状態を検出してカウンタをリセット

### バイナリ →BCD 変換（簡易版）

74x163 の出力は 4 ビットバイナリのため、0 ～ 9 の範囲で以下のように接続:

```
74x163 Q0 (pin 14) ---- 74x141 A (pin 15)
74x163 Q1 (pin 13) ---- 74x141 B (pin 14)
74x163 Q2 (pin 12) ---- 74x141 C (pin 13)
74x163 Q3 (pin 11) ---- 74x141 D (pin 12)
```

10 でリセットされるため、実質的に 0 ～ 9 の BCD カウンタとして動作

### スタート/ストップ制御回路

```
[スタートSW] ---+--- 74x132 (デバウンス) --- 74x74 D (pin 2)
                |                            74x74 CLK (pin 3) = パルス生成
                +--- [0.1μF] --- GND
                +--- [10kΩ] --- +5V

74x74 Q (pin 5) ---- 74x08 (AND) ---- 74x163 CEP (pin 7)
                |                  |
[ストップSW] ----+--- 74x132 -------|

74x74 /Q (pin 6) --- LED表示（実行中インジケータ）
```

### クロック発振回路（NE555、2 モード切替）

```
[+5V]
  |
  +---- NE555 pin 8 (VCC)
  |
  +--[トグルSW]---+-- [0.01μF] --- 高速モード（約100Hz）
  |              |
  |              +-- [1μF] ------- 低速モード（約1Hz）
  |                      |
  +--[可変抵抗 100kΩ]---+--- NE555 pin 6/7
  |                      |
  +--[1kΩ]--------------+
  |
  +---- NE555 pin 4 (RESET, プルアップ)

NE555 pin 3 (OUTPUT) ---+--- 74x08 (AND, イネーブル制御経由)
                        |
                        +--- 74x163 CLK (pin 2)
```

### 全体接続図

```
[NE555発振器] → [74x08 ANDゲート] → [74x163カウンタ] → [74x141] → [ニキシー管]
                      ↑
                 [74x74制御FF]
                      ↑
              [スタート/ストップSW]
```

## 配線の注意事項

### 10 進リセット回路

- 74x163 が「10」(1010) を出力した瞬間に LOAD 信号をアクティブにする
- LOAD (pin 1) はアクティブ LOW のため、インバータを経由させる
- タイミングによっては「10」が一瞬表示される可能性あり（許容範囲）

### スイッチのデバウンス

- スタート/ストップスイッチは必ず 74x132 でデバウンス処理
- チャタリングにより複数パルスが発生すると、意図しない動作になる

### クロック発振器の調整

- 可変抵抗で速度を微調整可能
- 高速モード: 人間の目では個別の数字が識別できない速度（視覚効果）
- 低速モード: ゆっくりとカウントアップ（動作確認用）

### 電源の安定化

- 高速カウント時は電源ノイズが発生しやすい
- 各 IC の電源ピン近傍に必ずデカップリングコンデンサを配置

## 表示器の対応について

### ニキシー管（BCD/冷陰極表示器）

- **最適**: 高速スクロール時の視覚効果が美しい
- **推奨管**: IN-14 (中型), IN-18 (大型) など視認性の良いもの
- **輝度**: 電流制限抵抗を調整して最適な明るさに設定

### LED 表示

- **可能**: ただし 74x141 を 74x42 に置き換える必要あり
- 高速スクロール時の POV（残像）効果は得られない
- 代わりに 7 セグメント LED + 74x47 の方が見やすい

### 7 セグメント LED 表示

- **不適合**: 74x141 は 7 セグメント用ではありません
- 同様の回路を 7 セグメントで実現する場合、74x47 を使用

## 動作電源の概要

### ロジック電源

- **電圧**: +5V (±5%)
- **電流**: 約 150mA（全 IC 合計）
- **推奨電源**: 500mA 以上の安定化電源

### ニキシー管駆動電源

- **電圧**: +170V ～ 180V（DC）
- **電流**: 10mA 以下（1 桁表示）
- **推奨電源**: DC-DC コンバータ

## 動作確認手順

### 初期確認

1. クロック発振回路の動作確認（オシロスコープ推奨）
2. 速度切替スイッチを低速モードに設定
3. スタート/ストップスイッチを OFF

### 通電テスト

1. +5V 電源を投入
2. +170V 電源を投入
3. ニキシー管が「0」または「9」を表示することを確認（初期値）

### カウント動作テスト（低速モード）

1. スタートボタンを押下
2. ニキシー管が 0→1→2→...→9→0 とゆっくりカウントすることを確認
3. ストップボタンを押下
4. カウントが停止し、現在の数字を保持することを確認

### ルーレット動作テスト（高速モード）

1. 速度切替スイッチを高速モードに切替
2. スタートボタンを押下
3. 数字が高速にスクロールし、個別に識別できないことを確認
4. 数秒後、ストップボタンを押下
5. スクロールが停止し、ランダムな数字が表示されることを確認

## トラブルシューティング

### カウントが 10 以上に進む

- 10 進リセット回路（74x08 での Q3 と Q1 の検出）を確認
- LOAD 信号が正しくアクティブになっているか確認

### カウントが不規則

- クロック信号にノイズが乗っている可能性
- 電源デカップリングを強化、GND を確実に接続

### スタート/ストップが効かない

- 74x74 の配線を確認
- 74x132 デバウンス回路を確認
- CEP (イネーブル) 信号が正しく制御されているか確認

### 高速モードで数字が見えない

- これは正常動作（目的の視覚効果）
- 速度を下げたい場合は、可変抵抗を調整またはコンデンサ値を増やす

## 回路の拡張性について

### サウンドエフェクトの追加

- 74x163 の出力をスピーカドライブ回路に接続
- カウント中は高速クリック音、停止時に効果音を鳴らす
- NE555 や圧電ブザーで実装可能

### 多桁ルーレット

- 74x141 と 74x163 を追加して 2 桁、3 桁に拡張
- 各桁を独立して制御し、順次停止する演出が可能

### 当選確率の調整

- 特定の数字で停止しやすくするロジックを追加
- 74x85 (比較器) で特定値を検出し、ストップ条件を変更

### LED イルミネーション

- カウント中は周囲の LED を点滅させる
- 停止時に当選数字に対応する LED を点灯

### シリアルインタフェース

- 74x165 (パラレル → シリアル変換) を追加
- 現在のカウント値を PC に送信し、ログ記録や統計処理

## 応用例

### デジタルダイス（サイコロ）

- 表示範囲を 1 ～ 6 に制限
- ボタンを押すたびにランダムな目を表示

### 抽選機

- スタートボタンで高速カウント開始
- 一定時間後に自動停止、当選番号を表示

### ゲーム用タイマー

- カウントダウンモードに改造
- 0 になったらブザーを鳴らす

### 教育用デモンストレーション

- 2 進数と BCD の変換を視覚的に理解
- カウンタ IC の動作原理の学習

## 設計上のヒント

### ランダム性について

この回路で生成される「ランダム性」は、人間がストップボタンを押すタイミングに依存します。真の乱数ではありませんが、エンターテインメント用途には十分です。

### 真の乱数生成

真の乱数が必要な場合:

- 外部ノイズ源（電源ノイズ、抵抗の熱雑音等）を増幅
- 74x74 でサンプリングし、LFSR (Linear Feedback Shift Register) に入力
- より複雑な回路が必要

### 速度調整のコツ

- 高速モード: 50 ～ 200Hz 程度が視覚効果として最適
- 低速モード: 1 ～ 5Hz 程度が動作確認に適切
- ストップ時のスローダウン演出を加えると臨場感が増す
